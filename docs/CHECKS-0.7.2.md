# WikiReader Next 0.7.2 — плавные переходы

## Поведение

Переходы добавлены к карточке объекта, выбору пересекающихся объектов,
экранам поиска/избранного/настроек, уведомлениям, форме подключения,
подтверждениям удаления и раскрывающимся разделам ID/сохранённых областей.
Содержимое вкладок появляется мягко; прежнее раскрытие карточки по высоте
сохранено с согласованной кривой движения. Карта и её жесты не анимируются
заново при каждой загрузке данных или вводе текста.

Основные переходы занимают 180–240 мс, раскрывающиеся секции — 180 мс.
WAAPI используется без дополнительных зависимостей. Панели/экраны/уведомления
анимируют transform/opacity; раскрывающиеся секции — высоту обёртки без padding,
чтобы закрытие доходило до нуля без скачка из-за внутренних отступов.

При закрытии состояние приложения меняется сразу: отменяются старые запросы,
обновляется навигация и фокус. Только визуальное содержимое остаётся на время
выхода, с inert, aria-hidden и отключёнными pointer events. Оно не доступно
для повторных действий и не объявляется скринридером. После выхода удаляется.

Быстрое повторное открытие отменяет старую анимацию и её completion callback.
Идентификатор визуального содержимого сохраняется на выходе: движение продолжается
с текущих transform/opacity вместо скачка в начальное положение.
При уходе приложения в фон текущий переход завершается. При отсутствии WAAPI
используется немедленное переключение.

Системная настройка prefers-reduced-motion учитывается при запуске и изменении
на лету: переходы немедленные, без выезда/затухания. Раскрывающиеся разделы
сохраняют семантику details/summary и управление клавиатурой. Поиск, прокрутка,
возврат в список, сохранение ключа и кэша используют прежнюю логику.
Системная Android-заставка регулируется ОС и в этом выпуске не менялась.

## Проверки и пределы доказательств

Новые браузерные регрессии: exit snapshot с inert/aria-hidden; быстрое переключение
экранов и reopen; reduced motion; раскрытие/закрытие summary; разворот закрытия
и клавиатура; завершение в фоне/смена motion preference; непрерывная opacity
при развороте направления (ошибка воспроизведена до исправления).

Команды: npm test; npm run test:probe; npm run android:sync;
npx playwright test; CI Gradle testDebugUnitTest assembleDebug lintDebug.
Итоговые числа, ссылка CI и проверка APK записываются в PR после выполнения.

API, подложка и native bridge в браузере подменены. Реальный FPS, плавность на
физическом Android/WebView, TalkBack и системные переходы устройства — NOT_RUN.
Автотесты подтверждают состояния/отмену/геометрию переходов, а не обещают 60 FPS
на любом устройстве. Новые API-запросы или аналитика не добавлены.
