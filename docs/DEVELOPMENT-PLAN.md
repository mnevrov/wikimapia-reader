# План продолжения — 18.10.2026

Цель: удобное чтение объектов Wikimapia на Android без собственного сервера.
Продолжаем существующий React/Leaflet/Capacitor-прототип. Условие полноценного
MVP: подтверждённые контуры области и детали через документированный API.

1. Сеть: отдельно OS DNS, HTTPS через штатный HTTPS proxy среды, JSON и ошибки API.
2. Адаптер: тесты на реальном сокращённом ответе объекта 55 и синтетических ошибках;
   исправить debug, фотографии, некорректные координаты и утечки ошибок.
3. UI: ввод ключа применяется кнопкой, запрос области вручную, чтение по ID,
   защита от устаревших ответов и переключения источника. Демо всегда подписано.
4. Android: сгенерировать проект, запретить HTTP/backup, выполнить assembleDebug;
   не заявлять APK при неуспешной сборке.
5. Проверки: unit + production build + браузерные сценарии с контролируемой сетью;
   отдельное независимое ревью и повторные проверки. Реальная сеть не подменяется
   моками в отчёте.

Выбор: официальный HTTPS API с личным ключом и нативным CapacitorHttp.
Чужой Nakarte proxy и недокументированные itiles не используются.
Ключ только в оперативной памяти. Данные API выводятся текстом.
Если область остаётся неподтверждённой, результат — укреплённый прототип,
а не объявление полноценного MVP.

## Уточнение по результатам исследования

Официальный deprecated `box` вернул реальные объекты. Основной путь MVP изменён
на `box` → `place.getbyid`; новый метод области сохранён в адаптере и пробнике
для дальнейшей проверки. Доступность `box` подтверждена повторным пробником.
