# WikiReader — фирменный стиль v1

WikiReader — **неофициальный клиент Wikimapia**. Слоган: **«Исследуй мир через Wikimapia»**.

Новый знак совмещает контур выбранного географического объекта и геометку. Он разработан независимо, не воспроизводит официальную символику Wikimapia и не предполагает официального партнёрства.

## Цвета и применение

| Роль | Цвет |
| --- | --- |
| Фон иконки / splash | `#063940` |
| Контур карты | `#14B89A` |
| Выделение / акцент | `#FF623B` |
| Светлый контраст | `#F5FEFC` |

- **Web-заставка:** `public/brand.svg` подключается из `index.html`, тема интерфейса не меняется.
- **Android 8+:** слои `ic_launcher` и `ic_launcher_round` из `mipmap-anydpi-v26` и векторный `@drawable/ic_launcher_foreground`.
- **Android 13+:** системная тематическая иконка использует `ic_launcher_monochrome` без собственных цветов.
- **Android 7.0–7.1 (minSdk 24):** векторные fallback-иконки в `mipmap-anydpi`; старые плотностные PNG сохранены, но векторные ресурсы должны иметь приоритет. Проверить это на эмуляторе API 24.
- **Native Splash:** использует ту же векторную композицию в `wikireader_splash.xml`.
- **Android Auto:** предусмотрен простой монохромный знак; наличие иконки само по себе не гарантирует появление приложения в Android Auto.

Подпись об источнике данных — **«Неофициальный клиент Wikimapia»** — остаётся на веб-заставке и в описании проекта. Не меняются схема данных, API-ключи, UI карты, GPS, Yandex и офлайн-хранилище.

## Контроль качества

1. Проверить запуск и отсутствие старой Android-иконки на API 24, 26, 33 и 36.
2. Проверить адаптивную обрезку квадрат/круг/сквиркл, системный themed icon на API 33+.
3. Проверить splash при холодном и тёплом старте, светлой/чёрной темах; главное — не менять настройки пользователя.
4. Выполнить unit, Android Gradle lint/build, браузерные и emulator-тесты из действующего CI.

PNG в пяти плотностях и исходные SVG подготовлены отдельно как экспортируемый дизайнерский набор. Для современных Android в репозитории используются векторы как первоисточник.
