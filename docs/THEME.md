# Чёрная тема — 0.3.0

По умолчанию приложение использует чёрную тему, даже если в системе выбрана
светлая. В «Настройки → Оформление» доступны три варианта: «Чёрная», «Светлая»,
«Как в системе». Выбор сохраняется на устройстве; режим «Как в системе» реагирует
на изменение оформления Android/браузера без перезапуска приложения.

Чёрными сделаны карточки, настройки, поля ввода, кнопки и элементы Leaflet.
Подложка OpenStreetMap сохраняет оригинальные цвета: она не инвертируется.
Отдельный тёмный слой карты — следующая задача, требующая проверки источника
и условий использования. Во время загрузки фон карты тёмный.

HTML применяет сохранённую тему до запуска React. Для Android задан начальный
чёрный фон WebView и splash; локальный AppearancePlugin переключает цвет значков
системных панелей и фон WebView. На Android 15+ панели могут рисоваться поверх
приложения; добавлены области под системные отступы. Нативная часть требует
дополнительной проверки на телефоне, особенно при жестовой навигации и смене темы.

Ключ API по-прежнему только в памяти. В localStorage сохраняются лишь выбранная
тема и избранные ID. AppearancePlugin принимает только dark/light и не получает
ключи или URL запросов. Системное оформление — отдельный параметр от демо/API.
