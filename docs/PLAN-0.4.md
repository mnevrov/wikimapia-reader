# План версии 0.4

Цель: читать реальные объекты с телефона, сохраняя максимум места для карты и текста. Личный ключ пользователь вводит локально; публичный example используется только в исследовании.

Порядок работ:
- [x] Области: страницы по 50, объединение по ID, кнопка «Ещё», счётчик found. Автозагрузка первой страницы через 900 мс после остановки карты; минимум 6 секунд между всеми API-запросами. Повтор области из ограниченного кэша без нового запроса. Ошибка останавливает автоповторы до ручного запроса. Уход в фон отменяет ожидания.
- [x] Android: Back закрывает настройки, затем карточку, затем сворачивает приложение. Сохранять центр/масштаб и настройки без ключа. Геолокация только по нажатию, один запрос, обработка отказа.
- [x] Комментарии: поле date — Unix seconds из реального ответа; русская дата, исходный ISO в time. Отсутствующие/невалидные даты не придумывать.
- [x] Дизайн: компактная шапка, отдельная нижняя панель действий, доступные кнопки 44 px, прокручиваемые вкладки, больше места тексту, адаптация к узким/широким экранам и безопасным отступам Android.
- [x] Проверить официальный поиск и источник тёмной карты. Добавлять только при подтверждённой работоспособности/условиях; иначе явно записать причину.
- [x] Node/Python/браузерные тесты, независимое ревью, clean APK + lint, проверка подписи и ресурсов, GitHub PR/CI.

Критичные проверки: смена области во время ответа, отмена queued запросов, ошибки второй страницы без потери первой, повтор страницы без дубликатов, программное перемещение при открытии карточки, видимость атрибуции, закрытие по Back. Скриншоты пользователя подтверждают работу API на телефоне версии 0.3; новые сценарии потребуют отдельной проверки телефона.

## Решения и журнал

- Изменения выполняются в отдельной ветке feat/mobile-reader-04 существующей рабочей копии. Повторное подтверждение не запрашивалось: пользователь поручил автономное последовательное выполнение.
- Legacy search подтверждён HTTP200; поиск показывает первые 20 результатов. Тёмная CARTO отложена: нужен отдельный ключ по актуальным условиям.
- Unit/браузерные регрессии выявили и закрыли ошибки stop()/blocked, пагинации прежней области и очистки demo. Независимый ревьюер подтвердил исправления.
- Повторная проверка: Node27, Python3, Chromium15 — PASS. Native clean assembleDebug/lintDebug завершены с exit0; подпись совпала с 0.3, ресурсы совпали с dist; физические проверки 0.4 не выдаются за выполненные.
