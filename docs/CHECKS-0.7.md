# WikiReader Next 0.7 — UX/UI

Матрица основных сценариев, критерии и источники: [UX-аудит](UX-AUDIT-0.7.md).
Реализованы возврат из карточки в источник (поиск/избранное), восстановление запроса,
списка и scroll, явный возврат; локальное распознавание ID/официальногоURL включая
fragment show; очистка/отмена поиска; локальный фильтр избранного; undo удаления8с
из списка и карточки; подтверждение удаления ключа и Back для его отмены;
подсказка отсутствия сети; клавиатурные вкладки и обработка отмены жеста;
48px контролы, крупнее основной текст, адаптивное чтение и исправленные подписи.

Существующие механизмы API/кэша/шифрования сохранены, новые endpoint не добавлены.
Ссылки в поиске разбираются как строка и не запрашиваются; чужой host, credentials,
порт, неверный ID отвергаются. Не сохраняется история поиска/аналитика/личный ключ
в веб-хранилище. Контуры не превращают подложку и описания в офлайн-данные.

Проверки: npm test; npm run test:probe; npm run android:sync;
npx playwright test; CI Gradle testDebugUnitTest assembleDebug lintDebug.
Новые браузерные регрессии покрывают return/query, ссылку, undo/reload/соседние записи,
подтверждение/Back, клавиатурные tabs,offline/online и размеры touch-контролов.
Проверка parse links — Node; прежние проверки API/кэша/поздних ответов сохранены.
Фактические числа/итоги и идентификатор сборки фиксируются в PR после выполнения.

В браузерных тестах API, подложка и native vault — mock. Скриншоты внутренних
проверок содержат синтетические данные и служат проверке компоновки UI.
Физический Android/IME/системный масштаб шрифта/TalkBack — NOT_RUN.
Проверка не является полной сертификацией доступности или пользовательским исследованием.
