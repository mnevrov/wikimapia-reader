# WikiReader 0.2.0 — подтверждённые результаты

Дата: **18 октября 2026, время Москвы**. Продолжение исходного проекта
`wikimapia-mobile-preflight.zip`.

**Результат:** реализован экспериментальный Android MVP: карта, реальные контуры
через документированный legacy `box`, мобильные карточки через `place.getbyid`,
описания, фото, комментарии и избранные ID. APK собран. Реального телефона или
эмулятора для проверки приложения не было.

Локальный DNS не удалось проверить положительно: HTTPS-подключения работали
через штатный proxy среды, который разрешает имя сам. Это не основание считать
DNS Wikimapia сломанным. Отдельное прямое TLS-рукопожатие без proxy не проверено.

После обнаружения рабочего `box` выполнены два повторных пробника. Оба завершились
с кодом 0. Файл `probe-map-chain.json` получен командой:

```bash
python3 scripts/probe.py --example --id 5195049 --out docs/probe-map-chain.json
```

HTTP 200 не считается успехом данных сам по себе: проверяются debug/error,
структура, описание, совпадение ID и допустимые координаты геометрии.
Глобальные гарантии доступности API по нескольким запросам дать нельзя.
Личный ключ не предоставлялся и не использовался.

## Исследование клиентов и выбранный путь

Nakarte получает контуры своим тайловым загрузчиком через собственный proxy,
а описание открывает в отдельном окне Wikimapia. Wikimapia Export использует
официальный старый `box` и преобразует polygon.x/y в GeoJSON. Старый Python-клиент
тоже опирается на официальный API. Ссылки и подробности — `DATA-SOURCES.md`.

Выбрано: **прямой HTTPS box → place.getbyid**, на Android через CapacitorHttp,
в браузере через fetch. Собственный сервер не требуется. `box` документирован,
но помечен deprecated; это существенный риск поддержки. Не использовались
чужие proxy/ключи, внутренние itiles, scraping или обходы ограничений.

## Выполненная реализация

- Работающая карта и выделяемые контуры; загрузка области — явной кнопкой.
- Описание в раскрывающейся мобильной карточке, отдельные вкладки фото/комментариев.
- Открытие по ID и выделение контура объекта; избранные ID в localStorage.
- Правильная схема folder/name у box, big_url у фото, name/message у комментариев.
- Удалённые комментарии и IP не выводятся; данные отображаются текстом без raw HTML.
- Ошибки debug и неоднозначные [] больше не отображаются как успешная пустая карта.
- Ключ применяется кнопкой и остаётся в памяти; не утекает в сообщения ошибок.
- Минимум 6 с между стартами API-запросов, отмена ожидания, защита от поздних ответов.
- Android logging/WebView debugging отключены; HTTP, mixed content и backup отключены.
- Ключ не встроен в APK. Фото Wikimapia переводятся на HTTPS; HTTP fallback нет.

## Независимое ревью

Отдельный read-only ревьюер самостоятельно повторил unit/Python/build/UI,
проверил соответствие реальной box-fixture и исходного ответа. Найденные дефекты
исправлены с регрессионными тестами. См. `REVIEW.md`. В ходе разработки новый
браузерный тест сначала падал из-за таймаута 5 с при интервале клиента 6 с; ожидание
результата исправлено, повторный запуск прошёл. Финальные логи прилагаются. Повторная инкрементальная Android-сборка выявила
конфликт старых compressed_assets; выполнена чистая пересборка вместо заявления
об успехе неудачной попытки.

## Ограничения и что проверять на телефоне

1. Нет подтверждённого запуска APK на физическом Android или эмуляторе.
2. Реальные Android HTTP, системные отступы, жест «Назад», поворот, клавиатура,
   восстановление после ухода в фон требуют device smoke-test.
3. Загружается первая страница до 50 объектов; пагинация, поиск и GPS не включены.
   Это не полное покрытие территории. При большом числе объектов сузьте область.
4. box deprecated; новый place.getbyarea в этой среде не подтвердился.
   У example общий лимит. Для регулярного использования создайте свой ключ.
5. Фото/комментарии зависят от того, что вернул API; ответы в ветках комментариев
   отдельно не разворачиваются. Полный офлайн-кеш не реализован.
6. APK — debug для личной проверки, стандартная иконка Capacitor; не release
   для магазина. Android minimum 24, target 36, пакет org.example.wikimapreader.

## Безопасная передача ключа

**Не присылайте ключ в чат.** Введите его локально в приложении либо запустите
`python3 scripts/probe.py --ask-key`. Ввод скрыт, ключ не попадает в argv, файл
или вывод пробника. Можно передать только полученный JSON-отчёт. API требует ключ
в query-параметре HTTPS: сам Wikimapia и локальный сетевой отладчик его увидят.
Без своего сервера исключить доступ владельца устройства к своему ключу невозможно.
