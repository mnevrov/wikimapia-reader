# UX/UI WikiReader 0.7

## Цель и метод

Основная задача приложения — исследовать места на карте и удобно читать информацию
на Android-телефоне. Вторичные задачи — найти конкретный объект и вернуться к нему.
Аудит охватывает все доступные функции текущего клиента и основные ветви их состояний;
утверждение о проверке всех теоретически возможных комбинаций не делается.

Проведены чтение реализации, когнитивный проход по сценариям, эвристическая оценка,
автоматические проверки поведения и просмотр макетов работающего приложения.
Реального исследования с выборкой пользователей и измерения времени задач не было.

Источники, проверенные 18.10.2026:
- [NN/g: 10 эвристик](https://www.nngroup.com/articles/ten-usability-heuristics/):
  понятный статус, контроль/выход, предотвращение ошибок, узнавание, минимализм.
- [Android: доступность](https://developer.android.com/guide/topics/ui/accessibility/apps):
  рекомендуемая область касания48 × 48 dp; контраст обычного текста 4.5:1; смысловые подписи.
- [WAI-ARIA: вкладки](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/):
  одна точка входаTab, стрелки/Home/End, связь вкладки с панелью.
- [Material3: bottom sheets](https://m3.material.io/components/bottom-sheets/guidelines)
  — ориентир паттерна дополнительного содержимого у карты. Страница требуетJS;
  детальные предписания, не доступные из текста страницы, не считаются исследованными.

Практические решения для этого клиента — инженерные выводы из источников,
а не заявления о наличии специального стандарта интерфейса Wikimapia.
48 CSS px проверяются в браузерном viewport; физические dp/WebView и TalkBack требуют
проверки на устройстве. Автотесты с pointer и клавиатурой не заменяют её.

## Матрица текущих сценариев

|Сценарий|Риск/ожидаемое поведение|Решение/проверка|
|---|---|---|
|Первый запуск без ключа|Демо принимается за реальные данные|Сохранены явные пометки вымышленных объектов и CTA подключения|
|Запуск с сохранённым ключом|Утечка ключа/показ демо до восстановления|Сохранён native vault и стартовый экран; прежняя регрессия|
|Ввод/замена ключа|Запросы при наборе/потеря старого при ошибке|Сохранение только явной кнопкой; ошибка оставляет старый ключ|
|Удаление ключа|Необратимый случайный тап|Добавлены объяснение последствий, Отмена и отдельное удаление|
|Ошибка чтения ключа|Неясный выход|Сохранена отдельная команда удаления повреждённой записи|
|Возврат из демо|Повторный ввод ключа|Ключ сохраняется, отдельное возвращение к реальным данным|
|Движение/масштаб карты|Потеря контекста/лишние запросы|Сохранены debounce, отмена устаревшего и кэш|
|Слишком крупный охват|Непонятная пустая карта|Сохранена просьба приблизить карту|
|Повторный заход в область|Мигающая загрузка|Свежий кэш без запроса; старые контуры с тихим обновлением|
|Соседние области|Неверное покрытие|Сохранён точный union только полных областей|
|Плотная область|Неясно, зачем ещё нажимать|Сохранена догрузка одним действием с прогрессом и пределом20страниц|
|Обновление вручную|Двойные запросы|Блокировка кнопки во время запроса; общий интервал 6 с|
|Пустой ответ|Путается с загрузкой/ошибкой|Сохранён отдельный текст «Здесь пока нет объектов»|
|Сеть пропала/вернулась|Кэш принимается за полный офлайн|Новая подсказка ограничений, скрывается приonline; запросы не блокируются navigator.onLine|
|Ошибка API/квота|Бесконечная активность|Сохранено прекращение неретрайных ошибок и ограниченные повторы транспорта|
|Геолокация|Разрешение при старте/срыв при отказе|Только по явной кнопке, статус и объяснение ошибки|
|Один контур|Маленькая цель|Сохранён допуск попадания 8 px и прямое открытие|
|Пересекающиеся контуры|Случайный объект|Сохранён chooser от меньших к большим|
|Закрытие chooser|Нельзя выйти|Закрытие кнопкой/Back/Escape/перемещением/resize|
|Карточка из карты|Карта теряет роль контекста|Bottom sheet и выбранный контур сохранены|
|Карточка из поиска|Теряется список и запрос|Теперь закрытие/Back возвращают к исходному списку; явная кнопка возврата|
|Карточка из избранного|Теряется список/прокрутка|Тот же возврат, восстановление позиции списка и фокуса исходной строки|
|Чтение длинного текста|Мелкий шрифт/узкая строка|Описание16px, межстрочный1.75; раскрытие сохранено|
|Фото|Пустой блок/непонятное действие|Сохранены empty-state, lazy loading, открытие оригинала внешней ссылкой|
|Комментарии|Неясная дата/мелкий текст|Сохранены реальные даты, увеличены текст и метаданные|
|Вкладки|Клавиатура заходит во все кнопки|Добавлены roving tabindex, стрелки/Home/End|
|Свайп/отмена жеста карточки|Ложное переключение|Добавлена обработкаpointercancel, кнопочная альтернатива сохранена|
|Ошибка/отмена описания|Старый ответ открывает другой объект|Сохранён token/abort и явный Повторить|
|Название в поиске|Лишняя нагрузка на API|Явная отправка; набор не вызывает запросов|
|ID/ссылка из сайта|Нужно искать отдельную функцию|Основное поле принимает название/ID/официальную ссылку|

|Медленный поиск|Нет контроля|Добавлены Отменить поиск и Очистить поиск|
|Пустой поиск/ошибка|Нет дальнейшего действия|Поясняющий текст; форма остаётся для нового запроса|
|Сохранение места|Нет подтверждения|Краткая обратная связь, выделенная кнопка|
|Большой список избранного|Трудно найти|Добавлен локальный фильтр названий, состояние без совпадений|
|Удаление избранного|Случайная потеря|Вернуть в течение 8 с без перезаписи других сохранённых мест|
|Срок/размер/закрепление кэша|Путается с загрузкой подложки|Явные размеры/даты и прежние ограничения, данные ключа отдельно|
|Обычная/полная очистка|Удаление закреплённого|Прежняя обычная очистка оставляетpin; полная требует подтверждения|
|Тема|Слепящий старт|Чёрная по умолчанию, светлая/системная сохранены|
|Маленький/альбомный экран|Мелкие цели/перекрытия|48px основных контролов, адаптивная карточка (в альбомной ориентации скрыта ручка, остаются кнопки), проверки 320/844|
|Фон/возврат в приложение|Потеря запроса/квота|Сохранены отмена очереди и безопасное возобновление|
|Back/Escape|Непредсказуемый выход|Сначала подтверждение удаления, экран, chooser, карточка с возвратом; затем минимизацияAndroid|

## Границы выпуска

Это оптимизация текущих функций. Нет маршрутизации, редактирования Wikimapia,
полного офлайн-пакета, автоматического геокодирования сторонним провайдером,
скрытых запросов при наборе, новой аналитики или передачи пользовательских действий.
История запросов намеренно не сохраняется. Избранное и контуры остаются на устройстве.

Проверка на физическом Android, IME/системный масштаб шрифта/TalkBack,
реальное удобство на улице и качество сети — отдельная проверка пользователя.
Подложка в браузерных тестах подменена; визуальная проверка UI не доказывает
контраст всех контуров на любой подложке или отсутствие всех проблем доступности.
