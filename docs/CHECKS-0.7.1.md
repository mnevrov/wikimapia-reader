# WikiReader Next 0.7.1 — больше пространства карты

Верхняя широкая строка поиска заменена значком. Поиск, масштаб, геолокация,
обновление и догрузка объединены в одну узкую панель у края карты.
Оставлены понятные accessible names и область касания 48 × 48 CSS px.
Догрузка — значок в той же панели, без большой плашки. Одно нажатие продолжает
прежнюю последовательную загрузку; прогресс объявляется через live region
и доступное имя. В ходе загрузки кнопка блокируется. Ошибки остаются текстом.

Leaflet zoom control заменён кнопками той же панели с вызовом методов карты.
Подложка, атрибуция и жесты сохранены. На телефоне панель скрывается при карточке;
на широком высоком экране смещается влево, освобождая место карточке справа.

Стартовый экран: векторный знак, название, пояснение и ненавязчивый индикатор.
Одинаковая компоновка существует до запуска JS и при восстановлении ключа.
Проценты и искусственная задержка не добавлены. Reduced motion учитывается.
Системный Android splash использует согласованный векторный знак на чёрном фоне.

Проверки: Node/Python, production build/Capacitor sync, Playwright, CI Gradle
unit/assembleDebug/lintDebug. Новые браузерные сценарии проверяют размер панели,
поиск/масштаб, запуск с отложенным mock vault и компактную догрузку. Прежняя
регрессия продолжения страниц проверяет функциональность догрузки одним нажатием.
Итоги и APK fingerprint фиксируются в PR после выполнения.

API/tiles/native bridge в браузере подменены. Реальный Android splash,
TalkBack и физический телефон — NOT_RUN. Никакие новые API-запросы не добавлены.
Версия 0.7.1/code10; прежняя подпись Next, установка поверх 0.7.0 без удаления.
