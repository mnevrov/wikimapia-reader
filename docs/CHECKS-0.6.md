# WikiReader Next 0.6 — покрытие кэша и работа с картой

## Реализованный скоуп

1. **Тихое обновление.** `background` отделён от первой загрузки. Контуры доступны
   во время запроса, вращается кнопка обновления, текстовая плашка отсутствует.
   `areaMessage` всегда пересчитывает статус после отмены/паузы, включая page=0.
2. **Общее покрытие.** `coverage.js` вычитает прямоугольники из непокрытой части
   viewport. Стыки и перекрытия учитываются, зазоры/отверстия не маскируются.
   Fresh RAM union проверяется до дискового обращения. Объединяются только
   полностью загруженные записи; частичная одиночная запись сохраняет пагинацию.
   Отдельный `complete` отличает завершение от остановки из-за повторной страницы.
   При известном недоборе `found > places.length` запись не считается полной.
3. **Читаемые контуры.** Обычные полигоны без заливки, линия 1.5 px. Выбранный
   объект — янтарная линия и заливка 0.12. Геометрия свежей карточки заменяет
   выбранный старый полигон, без двойной заливки. Если API не вернул геометрию,
   известный контур сохраняется.
4. **Выбор пересечений.** Проверяются внутренность и расстояние до границы 8 px.
   Один объект открывается сразу, несколько — списком от меньшей площади к большей.
   Back/Escape, перемещение и изменение размеров карты закрывают выбор. Список
   прокручивается, поддерживает короткий альбомный экран и не перекрывает навигацию.
5. **Управление кэшем.** В настройках видны объём сериализованных данных, число
   областей, даты обновления и закрепление. Можно перейти к области на карте,
   выбрать срок 1/7/30 дней, закрепить текущие части покрытия или отдельную запись.

## Хранение и пределы

IndexedDB `wikireader-areas` обновляется с версии 1 до 2, прежний store `areas`
сохраняется, добавлен store `settings`. Настройка срока хранится на устройстве.

Общие пределы: 32 записи и 12 МиБ сериализованных данных; размер файлов WebView
с накладными расходами может отличаться. Закреплённые области входят в эти пределы,
не вытесняются по возрасту или ради обычных записей. Обновление через API сохраняет pin.
Если все пределы заняты закреплённым, новые обычные записи могут не сохраниться;
нужно открепить ненужное. Переполнение/ошибка закрепления не выдаются за успех.

Обычная очистка удаляет незакреплённые записи. Полная — отдельная кнопка и явное
подтверждение «Удалить всё». Предпочтение срока сохраняется. Запись, политика,
закрепление и очистка выполняются в одной очереди/атомарных IDB-транзакциях.
При ошибке диска остаются прежние данные и сетевой режим. Записываются только
изменившиеся записи, чтение свежего объединённого покрытия памяти не вызывает
перезапись дискового кэша.

Кэш содержит публичные названия/ID/контуры, bbox, время и метаданные пагинации/pin.
Ключи, URL запросов, описания, комментарии и фотографии исключены белым списком.
Контуры разных API-ключей используют один публичный кэш на устройстве. Никаких
новых endpoint, внутренних itiles, чужих proxy или увеличения частоты API нет.

## Проверки и границы доказательств

Локальные команды: `npm test`, `npm run test:probe`, `npm run build`,
`npx playwright test`, `npx cap sync android`.

Node (57 тестов) проверяет точное покрытие/зазоры, partial/stalled pages, TTL/pin/capacity,
дисковое восстановление, отмену/старые ответы, quiet status и hit testing.
Браузерный набор (37 сценариев) проверяет UI, реальные pointer-нажатия, Back/drag/resize,
миграцию v1, pin+reload, очистку обычную/полную, ошибку записи, обновление pin,
карточку без геометрии и все прежние сценарии ключа/поиска/тем/комментариев.

Тесты используют mock API, native bridge, геолокацию и подложку. Личный ключ
не использовался в тестах, логах, git или CI. Реальная скорость Wikimapia и
физический Android/WebView/Keystore с этой версией — NOT_RUN.

GitHub CI запускает полный Node/Python/Playwright набор, JVM `testDebugUnitTest`,
`assembleDebug` и `lintDebug`. Подтверждённый итог CI и проверка финального APK
фиксируются в PR после выполнения, без заявлений о физическом запуске.

## Ревью

Независимое read-only ревью выявило и помогло закрыть:
- ложную полноту после пустой/повторной страницы при известном недоборе;
- исчезновение известного выбранного контура при пустой геометрии карточки;
- лишнее дисковое обращение при готовом union в памяти (оптимизация).

Проверка поворота экрана также выявила оставшийся chooser после resize:
закрытие добавлено на `moveend`, регрессия включена в браузерный набор.

## Установка

Версия 0.6.0 / code7, package `org.example.wikimapreader.next`, Android 7+.
APK для пользователя подписывается сохранённым сертификатом Next, поэтому
предназначен для обновления 0.5.x без удаления приложения. Сырой CI APK подписан
временным ключом runner и не заменяет передаваемый переподписанный файл.
