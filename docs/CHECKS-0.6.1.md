# WikiReader Next 0.6.1 — догрузка одним нажатием

## Причина и изменение

В 0.6.0 автоматическая загрузка останавливается после трёх страниц, а каждое
нажатие «Показать ещё объекты» запрашивает только одну следующую страницу.
Запрос охватывает экран с запасом до 20% вокруг него, поэтому новые объекты могут
находиться за видимыми краями. Визуально заполненная карта не доказывает полноту
ответа API. Фактический сетевой ответ с телефона пользователя не записывался.

В 0.6.1 кнопка «Догрузить область» запускает последовательную загрузку оставшихся
страниц и показывает число полученных объектов. Кнопка блокируется на время цепочки.
Автоматический предел первых трёх страниц и общий интервал запросов не менее
6 секунд сохранены. Нет новых endpoint, обходов ограничений или собственного сервера.

Цепочка прекращается при завершении, ошибке, странице без новых объектов,
перемещении карты, открытии карточки/другого экрана, сворачивании приложения.
Поздний ответ отменённой операции не меняет новую область. Ошибка сохраняет
уже загруженное; повторное действие продолжает с неудавшейся страницы.
Для очень плотных/меняющихся областей предел одного действия — 20 дополнительных
страниц. При достижении предела показывается объяснение и возможность продолжить.
Частичная область не помечается полной. Метаданные цепочки не сохраняются в кэш.

## Проверки

Регрессии Node: несколько страниц за одно действие, остановка на повторной странице,
ошибка и продолжение, отмена с поздним ответом, конечный бюджет и возобновление.
Браузерная регрессия: первые три страницы, одно нажатие до шестой, прогресс,
исчезновение кнопки после завершения, reload без запроса при полном свежем кэше.
Полный набор команд: npm test; npm run test:probe; npm run android:sync;
npx playwright test; Gradle testDebugUnitTest assembleDebug lintDebug в GitHub Actions.
Фактические результаты CI фиксируются в PR после выполнения.

API/подложка/native bridge в браузерных тестах подменены. Личный API-ключ
не используется и не попадает в git/логи. Физический Android и реальная задержка
Wikimapia для этой версии — NOT_RUN.

Версия 0.6.1 / code8, org.example.wikimapreader.next, Android 7+.
Передаваемый APK подписывается сохранённым сертификатом Next для обновления поверх
0.5.x–0.6.0. Сырой APK runner использует другую временную подпись.
