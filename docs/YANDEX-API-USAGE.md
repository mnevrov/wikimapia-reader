# Яндекс API в WikiReader — бесплатный режим без лишних запросов

## Проверено по официальным правилам (19.10.2026)
- Обычные **map hits** JavaScript API 3.0 бесплатны. Их не следует смешивать
  с платными тарифами на панорамы, геокодирование, поиск организаций и др.
  Источник: https://yandex.ru/maps-api/docs/news/new-billing/tariffs.html
- Для бесплатного JavaScript API лимит панорам — **100/сутки**;
  геокодирование — **1 000/сутки**. WikiReader не вызывает эти методы.
  Источник: https://yandex.ru/legal/maps_api/ru
- Tiles API — отдельный продукт: до **30 HTTP tile-запросов/секунду**,
  но у него нет подтверждённого тёмного набора тайлов.
- Данные Wikimapia загружаются только через Wikimapia API. **Нельзя
  пересылать к Яндексу поисковые запросы по названиям, комментарии или
  описания объектов:** функции поиска Яндекса не нужны.

## Не создавать лишнюю нагрузку
1. **По умолчанию только OSM/Leaflet.** Ключ Яндекса сам по себе НЕ
   включает загрузку JS API и не отправляет запросы.
2. Яндекс включается только при явном выборе пользователем соответствующего
   режима. Исключены невидимое предварительное подключение и CI-запросы с ключом.
3. Создавать **один экземпляр YMap на сессию выбранного режима**, а не на каждую
   карточку, вкладку, изменение темы или панорамирование. Изменение темы — update
   существующего YMap. Не инициализировать карту для генерации предпросмотров.
4. `src/yandexUsage.js` — единый шлюз загрузки SDK. Проверяет явное включение,
   наличие ключа, готовность Referer и допустимость бесплатной лицензии;
   объединяет параллельные вызовы; после ошибки запрещает повторные запросы
   на 60 секунд; не позволяет незаметно менять ключ без перезапуска WebView.
5. При ошибке/недоступности Яндекса переключиться на OSM без бесконечных
   сетевых повторов. **Не подменять тайлы OSM источником, не указанным в лицензии.**
6. Все тесты запускаются с мок-API и вымышленными ключами. Никогда не включать
   рабочий ключ в GitHub Secrets для обычных unit/Playwright-тестов, логировать
   его или хранить внутри git/публичных URL.

## Обязательные правовые и технические условия перед включением
- В Яндекс JS API 3 требуется ключ с настроенным HTTP Referer:
  https://yandex.ru/maps-api/docs/js-api/common/quickstart.html
- Для Android WebView требуется отдельно проверить реально передаваемый Referer.
  Условия для мобильных приложений описывают формат
  `http://<идентификатор_приложения_в_сторе>.ymapapp`.
  Существующее Capacitor origin (localhost) не следует считать равнозначным
  этому Referer без проверки. Не выдавать фиктивный store ID за настоящий.
  https://yandex.ru/legal/maps_api/ru
  https://yandex.ru/maps-api/docs/js-api/limit.html
- Репозиторий и APK WikiReader Next публично доступны на GitHub с 19.10.2026.
  Бесплатную лицензию применяют только при выполнении всех требований Яндекса.
  Пользователь вручную подтверждает настройку HTTP Referer; без него SDK не грузится.
  Наличие публичного GitHub Release само по себе не подтверждает соблюдение ВСЕХ условий.
- На карте сохраняются встроенные авторские обозначения Яндекс JS API 3.0;
  интерфейс WikiReader не должен удалять/скрывать копирайты SDK.
  Актуальные условия: https://yandex.ru/legal/maps_termsofuse/ .
- Для контроля фактического потребления использовать **статистику личного
  кабинета разработчика Яндекса**, не локальный счётчик загрузок: Яндекс считает
  запросы на своей стороне. Это единственный надёжный источник квот.
- Клиентский JS API-ключ виден в запросах SDK; он не может быть скрытым секретом.
  Поэтому обязательно ограничить его Referer, не оставлять без ограничений.
- Ни один из присланных пользователем ключей не был включён в этот коммит.

## Состояние внедрения
Реализовано: опциональная синхронизированная дневная/ночная подложка YMap 3.0
  за Leaflet. Leaflet остаётся владельцем жестов, контуров и API Wikimapia.
  Яндекс не получает геокодирование, фото, поиск и комментарии Wikimapia.
  Выбор подложки, ключ JS API и подтверждение HTTP Referer задаются в настройках.
  Рабочий ключ нигде в исходниках/публичных билдах не зашит.
  На Android следует проверить фактический Referer (Capacitor origin обычно
  `https://localhost`) и установить разрешённый домен в кабинете Яндекса;
  нельзя подделывать Referer без проверки и нельзя трактовать localhost
  как подтверждённый без реального устройства. При отказе SDK — OSM.
  Playwright запускает только mock SDK; настоящая РФ-сеть/Android-телефон НЕ проверены.

## Синхронизация схемы с темой (0.9.1)
- Чёрная тема приложения включает тёмный стиль YMap и YMapDefaultSchemeLayer; светлая — дневной. Режим «Как в системе» следует текущей системной теме.
- Переключение выполняется `YMap.update({theme})` **и** `YMapDefaultSchemeLayer.update({theme})`, чтобы схема слоя не осталась светлой при тёмном интерфейсе. Карта не пересоздаётся, географическое положение и выделения сохраняются. Отсутствуют повторные загрузки SDK из-за смены темы.
- Повторные применения той же темы пропускаются. Ошибка SDK вызывает возврат на OSM.
- Проверяется через Playwright с вымышленным SDK и без настоящего ключа; реальный цвет тайлов на Android требует отдельного smoke-test.

## Диагностика подключения (0.9.2)

1. После неудачной попытки включить «Яндекс Карты» откройте Настройки → Подложка карты. Приложение показывает безопасный код: `script-load-error`, `script-timeout`, `sdk-global-missing`, `sdk-ready-error`, `sdk-map-error`, `retry-cooldown` или `reload-required`. Сообщение **не обвиняет HTTP Referer без доказательств**.
2. «Скопировать диагностику» формирует текст без ключа, URI скрипта и сырых ошибок SDK. Проверки через Playwright используют вымышленные ключи.
3. «Адрес страницы WebView» — источник локальной страницы приложения; фактический заголовок `Referer` он не подтверждает. Для анализа запросов Android WebView понадобится отдельная проверка на устройстве.
4. После неудачной загрузки попытки ограничены 60-секундным cooldown; принудительно закрывать приложение необязательно, но при **смене ключа** внутри одной WebView-сессии потребуется перезапуск.
5. Бесплатная карта Яндекса загружается только после явного выбора; другие платные сервисы не запрашиваются. В тестах никогда не использовать личный ключ.

## Официальная атрибуция Яндекса (0.9.3)

- YMap JS API 3.0 уже создаёт официальный логотип, копирайты, кнопку «Открыть в Картах» и ссылку на лицензию. **Не добавляйте вторую «© Яндекс Карты» поверх карты**; удалена дополнительная ссылка `yandex-provider-link`.
- Скрывать, заменять, накрывать интерфейсом или менять ссылки/логотип SDK **запрещено**. Атрибуция Leaflet для OSM показывается только в режиме OSM; в режиме Яндекса остаётся официальная атрибуция JS API.
- Браузерный тест использует подставной SDK с имитацией атрибуции, проверяет отсутствие второго логотипа, его сохранение при смене темы и возврат атрибуции OSM при переключении.
- Реальная проверка размещения и доступности клика по SDK-атрибуции на Android WebView остаётся необходимой. Сам SDK не модифицируется.
