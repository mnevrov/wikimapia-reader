# Диагностика резервного API (0.14.3)

Основной источник WikiReader Next — сайт Wikimapia, **личный API-ключ необязателен**. Эта функция предназначена только для исследования резервного API и **не устраняет** проблемы маршрутизации, лимита или квоты.

В приложении Android откройте «Настройки → Диагностика Wikimapia». Если добавлен личный ключ и деморежим выключен, вручную нажмите «Проверить два HTTP-транспорта».

Сначала запускается запрос `box` с Android Native HTTP и диагностическим timeout до 20 секунд, затем такой же WebView `fetch` с timeout 20 секунд. Оба используют одинаковую фиксированную **публичную** область, не GPS пользователя. Между запросами не менее 6 секунд через общий gate приложения. **После quota/auth второй запрос не выполняется**. Не чаще, чем позволяет кабинет Wikimapia.

Кнопка «Скопировать результат проверки» копирует только агрегированные категории, длительность, коды HTTP, счётчики объектов и разрешённый серверный код `1004`. Не копируются ключ, URL, координаты, IDs, имена, комментарии, тела ответов, raw exceptions. HTTP 200 + `1004` означает отказ сервера, а не успешное получение контуров.

Предыдущие подтверждённые результаты из Issue #16: без VPN на физическом телефоне тайм-аут в обоих транспортах; с VPN HTTP 200 с `debug.code=1004`. Это не доказывает конкретное окно квоты и не характеризует работу **основного сайта**. Перед дальнейшим выпуском проверьте штатную работу 0.14.3 без ключа на Wi-Fi и мобильной сети. Не публикуйте API-ключ или полный URL теста.
