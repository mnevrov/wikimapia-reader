# Диагностика Wikimapia API на физическом Android (PR #32)

Эта процедура **не** предназначена для обхода ограничений Wikimapia и не заменяет проверку на реальном устройстве. Приложение «WikiReader Diagnostics» с отдельным Android applicationId устанавливается рядом с WikiReader Next.

## Подготовка

1. Установить **отдельную тестовую APK из успешного CI** PR #32.
2. Ввести действующий личный API-ключ через настройки **только на устройстве**. Не публиковать ключ в GitHub Issues, ссылках, скриншотах, логах или сообщениях.
3. Если ключ ранее был раскрыт, сперва отозвать/перевыпустить его в кабинете Wikimapia, обновить собственные приложения и не использовать раскрытый ключ в диагностике.
4. Не запускать повторные проверки при уже известном отказе по квоте; уважать лимит, показанный в кабинете ключа.

## Проверка

В **Настройки → Диагностика Wikimapia → Проверить два HTTP-транспорта** вручную запускается запрос `box` на фиксированной публичной области (не GPS пользователя). Порядок:
- Android Native `CapacitorHttp.get` с диагностическим лимитом 20 секунд.
- WebView `fetch` с 20-секундным лимитом, если первый транспорт не получил отказа API типа `quota` или `auth`.
- Между стартами запросов выдерживается не менее шести секунд через общую очередь. **Не более двух запросов на нажатие**, без автоматических повторов.
- При отказе `quota`/`auth` на первом запросе второй пропускается, а `requestCount` показывает реальное количество начатых вызовов.

Пример безопасного результата отказа:
```json
{
  "schema": 1,
  "kind": "manual-android-transport-test",
  "apiMethod": "box",
  "sample": "fixed_public_test_area",
  "requestCount": 1,
  "containsKey": false,
  "containsUrl": false,
  "results": [{
    "transport": "android_native",
    "outcome": "api_rejection",
    "httpStatus": 200,
    "reason": "quota",
    "apiCode": 1004,
    "contentCategory": "json",
    "objects": null,
    "polygons": null
  }]
}
```

Реальный отчёт также включает время запуска и длительности запросов. `apiCode=1004` записывается **только** при точном совпадении с исторически известным кодом Wikimapia `1004` («Key limit has been reached»). Любой другой, в том числе похожий, код остаётся `null`; `reason=quota` без `apiCode=1004` **не доказывает конкретный вид лимита**. HTTP 200 может сопровождаться ошибкой API и не означает успешную загрузку объектов.

## Конфиденциальность и ограничения

В отчёте нет ключа, URL с параметрами, координат, геометрии, ID объектов, имён, сырого `debug.message`, HTTP-тел или сторонних идентификаторов. Диагностика не отправляет результаты автоматически. Нельзя копировать/выкладывать секретные запросы из внешних средств отладки.

`transport_error` и `timeout` не идентифицируют DNS, TCP или TLS-этап сами по себе. Наличие ответа только через VPN характеризует **проверенный сетевой маршрут**; это не доказательство глобальной блокировки сервиса. Диагностическое приложение имеет отдельный идентификатор и может отличаться от основного приложения настройками маршрутизации VPN.

Issue #16 не закрывать до подтверждения реальной геометрии на Android. Изменения по Android Auto PR #12 не затрагивать.
