18.10.2026. Изменения выполняются по поручению пользователя: сохранение API-ключа и переработка интерфейса.

| Python | PASS, 3 | Проверки диагностического скрипта без сети |
| JVM JUnit | PASS, 3 | AES-GCM roundtrip, случайные nonce, неверный ключ, повреждение, неверная версия записи |

| Android CI build/lint/unit | [Статус проверки в PR/Actions](https://github.com/mnevrov/wikimapia-reader/actions/workflows/android.yml) | Выполняется отдельно; APK выдаётся только после успеха |

В browser-тестах API/тайлы заменены ответами, native vault — симуляцией моста с состоянием
в тестовом процессе, без секретов в DOM/localStorage/sessionStorage. Это доказывает сценарии
UI/моста и отсутствие browser fallback, но не работу Android Keystore на устройстве.
JVM-тесты действительно исполняют production CredentialCipher с JCE-провайдером.
Они не доказывают TEE/StrongBox-защиту.

## Изменённые сценарии

- Первый ввод → сохранение → автоматическое подключение.
- Повторный запуск → restore до показа карты → реальный режим.
- Замена ключа → только после успешной записи → старые запросы отменяются.
- Ошибка save/delete → показ ошибки, прежний ключ не подменяется.
- Ошибка restore → можно ввести заново или удалить повреждённую запись.
- Демо сохраняет native запись; после перезапуска используется сохранённый ключ.
- Избранное разделено source+id; старые неразмеченные записи мигрируют в реальные ID без вымышленных названий.
- Поиск и избранное больше не находятся в настройках. Back возвращает на карту, затем закрывает карточку.
- Вкладки комментариев/фото раскрывают карточку; жест ручки управляет высотой/закрытием.

## Что исправило независимое ревью

1. Пересечение synthetic/реальных ID в избранном: source+id и явное открытие соответствующего источника.
2. Низкий контраст light primary: semantic --on-accent.
3. Сырой error.message мог показать URL с key при русскоязычной подстроке запроса.
   Собственные ошибки теперь ValidationError; ошибки транспорта не выводятся как сырой текст.
4. Нечитаемый vault получил явное удаление сохранённой записи.

## Защита хранилища

AES-256-GCM / nonce12 / tag128 / AAD, ключ AndroidKeyStore. Native queue из одного worker.
Ciphertext сериализован с версией формата в приватных SharedPreferences. commit() проверяется;
ошибки не раскрывают исходное исключение. Credentials исключены из cloud backup и device transfer;
allowBackup=false. На web постоянное хранение намеренно отсутствует.

## Установка

Из-за отсутствия прежнего debug keystore версия WikiReader Next устанавливается с applicationId
org.example.wikimapreader.next рядом с исходным клиентом. Удалять старое приложение не требуется.
В новой версии ключ потребуется ввести один раз. Новый developer keystore хранится отдельно от git;
он относится к подписи APK, не является ключом Wikimapia. APK CI имеет временный signer и перед
выдачей переподписывается сохранённым developer signer. Совпадение с подписью 0.4 не заявляется.

## Ручная проверка телефона

1. Сохранить ключ → закрыть/принудительно остановить Next → открыть: контуры должны загрузиться без повторного ввода.
2. Проверить замену, удаление и повторный запуск после удаления.
3. Проверить, что включение демо не удаляет сохранённый ключ.
4. Карта → контур → комментарии → свернуть/развернуть жестом → Back.
5. Поиск → результат, избранное → место; проверить поворот, клавиатуру и системные отступы.
