# Разрешение на публикацию 0.15.1 Beta

По явному запросу владельца 08.11.2026 публикуется только **GitHub prerelease (Beta)** с совместимой подписью Android, чтобы можно было проверить единую APK с расширенными карточками.

- Не назначать эту версию Latest/stable.
- Не отмечать аппаратную приемку Android Auto, Яндекс-атрибуции или GPS Follow как пройденную по одному CI.
- Сохранять незакрытыми #42 и #51 до фактических тестов.
- Сохранить `docs/releases/0.15.0/HOLD_RELEASE.md`; он продолжает запрещать стабильный выпуск 0.15.0.
- Если есть одновременно `BETA_RELEASE.md` и `HOLD_RELEASE.md` для одной версии, подписывание должно быть заблокировано.

Публикация Beta не снимает ограничений Android Auto, не меняет требования лицензирования Яндекс Tiles API и не подменяет физическую проверку.
