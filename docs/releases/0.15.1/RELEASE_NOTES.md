# WikiReader Next 0.15.1 — Beta: единая APK для Android и Android Auto

**Статус:** публичная тестовая версия (GitHub prerelease), не стабильный выпуск. По прямому запросу владельца от 08.11.2026 объединённый исходный код опубликован в `main` и доступен для установки с прежней подписью. Аппаратная приёмка Android Auto не заявляется.

## Что входит

- Единый APK / package `org.example.wikimapreader.next`: обычная карта Wikimapia на телефоне и нативный Android Auto без отдельного APK AutoDev.
- Карта Android Auto с OSM или Yandex Tiles API (отдельный пользовательский ключ, вводится на телефоне, хранится в Android Keystore), безопасным резервным переключением на OSM и уменьшенным логотипом Яндекса.
- По запросу владельца оригинальные светлые цвета подложки и в дневной, и в ночной теме автомобиля, без ColorMatrix, автоматической инверсии и искусственного затемнения.
- Более подробная карточка объекта Android Auto: компактный просмотр поверх карты, кнопка «Подробнее», описание, маршрут, избранное, комментарии и счётчик фото. Полный текст и переход к фотографиям доступны только на стоянке, где разрешает автомобильный host.
- Парсер site-first для описания, фото и комментариев из общедоступной страницы Wikimapia; fallback к официальному API при наличии личного ключа.

## Установка

Устанавливайте `WikiReader-Next-0.15.1.apk` поверх официальной `0.14.6`, если версия и сертификат совпадают; конвейер выпуска отдельно проверяет сохранение предыдущей подписи. Временные debug APK из Actions или переподписанные варианты могут потребовать удаления перед установкой — они не являются совместимыми обновлениями. Удаление приложения может привести к потере локальных данных: заранее экспортируйте избранное и офлайн-области.

## Известные ограничения и оставшиеся проверки

- Нельзя считать проверенными отображение и интерактивность карты на Honor V2 с Android 16 в реальном автомобиле, GPS Follow во время поездки и переключение раскладки/ориентации.
- Официальную атрибуцию Яндекс Tiles API (графический логотип, переход по ссылке и взаимодействие на конкретном Car host) необходимо подтвердить до стабильного выпуска: #42 и #51 остаются открыты.
- В Android Auto нет полноценной галереи; фотографии открываются в мобильной версии. При движении ограничения отображения и прокрутки задаёт Android Auto.
- Доступность информации Wikimapia зависит от сервиса, сети и его лимитов. При ошибках site-first может потребоваться API-ключ.

**Это Beta-версия для практического тестирования, не утверждение о прохождении аппаратной сертификации Android Auto.**
