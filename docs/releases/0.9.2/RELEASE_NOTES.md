# WikiReader Next 0.9.2 — диагностика Яндекс Карт

## Изменения
- Вместо общего сообщения об ошибке Яндекс API приложение показывает **этап и код сбоя**: ошибка загрузки скрипта, тайм-аут (14 с), отсутствие объекта SDK, ошибка готовности SDK, сбой создания карты, пауза повтора и необходимость перезапуска WebView при смене ключа.
- В настройках **Подложка карты** сохраняется последняя ошибка и выводится короткая инструкция, что проверять дальше. Показан адрес происхождения страницы WebView (например, https://localhost), но это **не доказательство фактически переданного HTTP Referer**.
- Кнопка **Скопировать диагностику** копирует только код сбоя, источник WebView и индикатор сети. Ключ JavaScript API, исходные URL с ключом, сырые ошибки SDK и детали запросов **никогда не копируются**.
- При ошибке остаётся резервная OpenStreetMap. При смене темы и открытии карточек повторная загрузка SDK не выполняется. Сохраняется защита от частых повторных запросов.

## Установка и сбор данных
1. Установить подписанный APK 0.9.2 поверх WikiReader Next 0.9.1.
2. В Настройки → Подложка карты оставить ключ JS API и подтверждение Referer, выбрать «Яндекс Карты» один раз.
3. Если возврат на OSM повторится, открыть настройки и нажать «Скопировать диагностику» либо сделать скриншот блока диагностики. Отправлять **только** этот отчёт, сам ключ не присылать.

## Проверки и ограничения
- Node и Playwright тестируют различные ошибки на подменённом SDK с вымышленным ключом.
- Реальная работа на Android WebView в российских сетях, фактический HTTP Referer и поддержка графических драйверов **не подтверждены**. Это релиз диагностики, а не заявление, что Яндекс уже отображается на конкретном устройстве.
- Яндекс JS API не включён автоматически; геокодирование/поиск/панорамы/маршруты не вызываются; необходим личный активный ключ и соблюдение правил лицензии.
- Android Auto PR #12 не затронут.
