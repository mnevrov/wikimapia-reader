# WikiReader Next 0.7.3

Карточка объекта теперь следует за пальцем при перетаскивании ручки.
Короткий жест плавно возвращает её, длинный или быстрый закрывает свёрнутую
карточку; развёрнутая карточка сначала сворачивается. Закрытие начинается
из текущего положения, без скачка. Исправлен обрыв анимации при возврате
в поиск и избранное, а также отмена касания и повторный захват панели.

## Установка

Скачайте WikiReader-Next-0.7.3.apk из Assets и установите поверх WikiReader Next
0.7.2 без удаления приложения. Подпись Next сохранена. Android versionCode 12,
package org.example.wikimapreader.next. Репозиторий приватный: для скачивания
из GitHub необходим вход в аккаунт с доступом к репозиторию.
