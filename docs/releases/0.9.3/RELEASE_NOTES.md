# WikiReader Next 0.9.3 — исправление дублирования подписи Яндекс Карт

## Исправлено
- На Яндекс-подложке раньше отображались **две подписи**: официальная от Yandex JavaScript API 3.0 и добавленная приложением чёрная плашка «© Яндекс Карты». Последняя удалена.
- **Официальные логотип, информация об авторах карты и ссылки Яндекс API сохранены.** SDK и его элементы не скрываются и не модифицируются.
- При возврате к OpenStreetMap показывается обычная атрибуция OSM. Подложка, режим светлая/тёмная, контуры Wikimapia, кэш, поиск и галерея не затронуты.

## Обновление
Скачать WikiReader-Next-0.9.3.apk из GitHub Releases и установить поверх 0.9.2 без удаления приложения и данных (подпись прежнего Next).

## Проверки и ограничения
- Проверка повторяющегося логотипа, смены темы и переключения Яндекс → OSM реализована через Playwright с мок-SDK (без настоящего API-ключа). В CI также выполняются остальные браузерные и модульные тесты, `testDebugUnitTest`, `assembleDebug`, `lintDebug`.
- В реальном Android WebView пользователь уже подтвердил доступность тёмной Яндекс-карты скриншотом; **исправленная раскладка SDK 0.9.3 не подтверждена на устройстве** до установки этого релиза.
- Ссылки официального SDK должны оставаться видимыми и действующими, как требуют условия использования. Ни один ключ пользователя не зашит в APK.
- Android Auto PR #12 не изменён.
