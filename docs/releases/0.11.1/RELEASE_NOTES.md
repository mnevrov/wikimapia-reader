# WikiReader Next 0.11.1 — улучшенная диагностика и устойчивость Wikimapia API

## Изменения
- Исправлено отображение источника контуров: свежие данные сервера больше не называются кэшем; при обновлении старого кэша указывается его фактический возраст.
- Отмена запроса (смена области или выход) отличается от сетевого тайм-аута; отменённые запросы не учитываются как ошибка для повторной загрузки.
- Неизвестный ответ с ошибкой Wikimapia API не запускает автоматический повтор; ошибки определяются по безопасным кодам и известным категориям.
- «Настройки → Диагностика Wikimapia»: число запросов, средняя задержка, категории сбоев и полнота областей. Только память процесса, ручное копирование и очистка, без API-ключей, координат и объектов.
- Для ручного сравнения `box` и `place.getbyarea` добавлен `scripts/probe_compare.py` с интервалом ≥6 секунд. Автоматическое переключение отключено.
- Новые синтетические контрактные fixtures и тесты для ошибок API при HTTP 200, приватности диагностики, статусов свежести и CLI сравнения.

## Обновление
Установите WikiReader-Next-0.11.1.apk поверх WikiReader Next 0.11.0 из GitHub Release. Данные приложения, избранное, офлайн-карточки и кэш контуров не требуют миграции. Идентификатор `org.example.wikimapreader.next` и постоянный сертификат подписи прежние; сверяйте SHA256SUMS.txt.

## Проверки и ограничения
- Официальный `place.getbyarea` документирован, но его пригодный живой контракт пока не подтверждён. Рабочим остаётся legacy `box`.
- Автоматизированные тесты и Android CI проверяются при сборке релиза в GitHub Actions; браузерные mock-проверки не равнозначны реальному API.
- Smoke-test с личным ключом, Android физическое устройство, поведение сети в разных регионах и энергопотребление: NOT_RUN, требуют ручной проверки.
- Скрипт comparison использует фиксированный публичный bbox и запускается явно; не содержит ключа в выходном отчёте.
- Функции Android Auto в другом PR не затрагиваются.
