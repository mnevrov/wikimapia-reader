# WikiReader Next 0.13.0 — места рядом и переносимая библиотека

## Что нового
- «Объекты в области»: фильтрация уже полученных контуров по названию и ID, категории «Все / Избранное / Офлайн», сортировка по названию, примерной площади полигона или расстоянию.
- «Рядом со мной»: однократный запрос местоположения с разрешения пользователя, перенос центра карты и сортировка объектов относительно полученной GPS-позиции. Непрерывный GPS Follow остаётся отдельной функцией.
- Нажатие на объект открывает карточку; действие «Показать контур» подсвечивает его и центрирует карту без новых запросов Wikimapia. Сортировка и фильтры сохраняются при возврате к списку.
- В карточке добавлены «На карте» и «Поделиться» официальной ссылкой Wikimapia. На Android открывается системный экран обмена; в браузере применяется Web Share API или копирование.
- Библиотека получила экспорт и импорт JSON: избранное, до 50 записей истории, тексты и комментарии офлайн-карточек. Импорт выполняется только после подтверждения и не заменяет имеющиеся карточки. На Android используется системный выбор файла без разрешения на весь накопитель.

## Приватность и ограничения
- Геолокация используется только локально, в JSON-архив не попадает. API-ключ также не включается, запросы Wikimapia не выполняются во время сортировки, фильтрации, импорта и экспорта.
- Расстояние приблизительное, считается до центра границ контура, а не до ближайшей точки многоугольника. Фильтры и сортировка доступны через раскрывающийся блок, чтобы список объектов оставался видимым на небольших экранах. Сортировка и «Рядом со мной» охватывают только **полученные на устройство** контуры и не обещают полного списка Wikimapia.
- Резервная копия содержит тексты пользователя; храните её аккуратно. Максимальный размер одного JSON-архива — 10 МБ; если данных больше, приложение сообщит об этом без частичного экспорта. **Фото и их бинарные данные не экспортируются**, импортированные текстовые карточки доступны без сети, но фотогалерею придётся сохранить повторно. Срок хранения и лимит офлайн-карточек остаются в настройках устройства; импорт не перезаписывает существующие записи.
- Просмотр контура из карточки работает, только когда его геометрия уже загружена в текущую карту или ответ подробностей. Отсутствующая геометрия не запрашивается специально.
- Используется документированный legacy HTTPS `box`; отключено автоматическое переключение на недокументированные API/прокси, интервал запросов ≥6 секунд.
- Android Auto остаётся в отдельном PR #12; его код и отдельная подпись не включены в 0.13.0.

## Обновление
Установите подписанный `WikiReader-Next-0.13.0.apk` из GitHub Release поверх 0.12.0. Package `org.example.wikimapreader.next` и прежняя подпись должны совпадать. Android `versionCode 25`; избранное, история, параметры карты, API-ключ в Keystore, IndexedDB-кэш областей и офлайн-карточек остаются в прежних форматах. Проверяйте `SHA256SUMS.txt`. Не устанавливайте CI debug APK поверх Next.

## Проверки
- Node unit tests: локальные расчёты, фильтрация, backup schema, приватность и обратная совместимость.
- Playwright: выбор контура, отображение карты, JSON-импорт и регрессии существующих экранов.
- Python offline contract tests, Gradle `testDebugUnitTest`, `assembleDebug`, `lintDebug`: через основной GitHub Actions workflow.
- Реальный Android, SAF file picker, выбор системного share, TalkBack, GPS и живой Wikimapia API: **NOT_RUN** до проверки на устройстве; mock/CI не заменяет эти тесты.
- Результаты и ссылку на успешный CI необходимо проверить до merge и публикации релиза.
