# WikiReader Next 0.14.2 — единое расположение уведомлений на карте

## Изменения

- Информация о GPS Follow, загрузке областей и ошибках теперь отображается в одном компактном слоте слева вверху карты, рядом с правой панелью действий.
- При использовании Яндекс Карт слот располагается **под официальной верхней кнопкой Яндекса**. Официальные логотипы, условия использования и элементы SDK не изменяются.
- Местоположение уведомлений **не меняется** при ошибке, успешном действии, увеличении/уменьшении карты и переходе в альбомную ориентацию.
- Кратковременные подтверждения и отмена удаления избранного показываются там же на экране карты, временно скрывая менее важную информацию. За пределами карты прежнее расположение подтверждений сохраняется.
- Сообщение об отсутствии сети занимает тот же слот, без одновременного перекрытия другими сообщениями.
- Исправлена ошибка приоритета: при неудачной загрузке объектов показывается **ошибка загрузки**, а не «GPS Follow приостановлен». GPS-подсказка остаётся резервной информацией и не подменяет ошибки Wikimapia или прогресс загрузки.

## Проверки

- Добавлены Node-тесты приоритетов: ошибка загрузки выше состояния GPS; ошибка выше GPS при низкой точности; прогресс загрузки выше сообщения о приостановке GPS.
- Обновлены Playwright-проверки размещения обычных сообщений, предупреждений, состояния без сети и подтверждений: портрет 390×844, 320×640 и альбомный 844×390; OSM и имитация расположения официальной кнопки Яндекса.
- Веточная CI проверяет Node/Python, Playwright и Android Gradle. Фактические результаты следует подтверждать по GitHub Actions перед выпуском.
- Проверка с физическим телефоном и реальным SDK Яндекс Карт остаётся отдельным ручным тестом; браузерная подмена класса `has-yandex` не подтверждает поведение SDK на устройстве.

## Установка и ограничения

Версия 0.14.2, Android versionCode 30. Установите `WikiReader-Next-0.14.2.apk`
из GitHub Release поверх текущего WikiReader Next. При успешном прохождении
автоматической процедуры выпуска пакет и постоянный сертификат останутся
совместимыми с предыдущей версией, без удаления данных.

Функциональность чтения объектов и Android Auto не изменяется. Внутренние
источники Wikimapia и их ограничения доступности остались прежними.
