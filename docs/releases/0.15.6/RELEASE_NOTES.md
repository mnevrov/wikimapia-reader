# WikiReader Next 0.15.6 — устранение мерцания контуров карты

## Подтверждённый симптом
На записи с Honor V2 / Android 16 (0.15.5) контуры Wikimapia исчезают и снова появляются на неподвижной карте как минимум дважды в течение первых восьми секунд. Отчёт schema 4 подтверждает, что серверные тайлы принимаются: 2/2 HTTP 200, 2/2 успешно декодированы, 2/2 родительского уровня, ошибок декодирования нет. Следовательно, симптом отличается от предыдущих ошибок запроса и парсинга.

## Исправления
- На телефонной карте React/Leaflet ранее подтверждённые контуры сохраняются при промежуточном состоянии нового запроса (page=0, пустой промежуточный список), вместо очистки слоя до поступления результата.
- Пересоздание AreaLoader (например, при очередном обновлении Android-кэша или восстановлении приложения) больше не сбрасывает слой контуров без изменения источника/режима.
- При переключении между demo и реальными данными слой по-прежнему сбрасывается, чтобы не отображать фиктивные объекты в рабочей карте.
- Успешный ответ с новыми объектами заменяет контуры; подтверждённая пустая область удаляет их. При перемещении карты границы видимости по-прежнему фильтруют старые полигоны.
- Не изменяются сайт/протокол Wikimapia, ограничение запросов, фоновые правила Android, Android Auto и настройки Яндекс-подложки.

## Проверки
- Добавлены Node-регрессионные тесты переходов: пустое промежуточное состояние, сохранение видимых контуров при загрузке, замена геометрии, подтверждённый пустой результат и отсечение объектов вне области.
- Штатный CI должен успешно выполнить Node/Python, Gradle unit/lint/assemble, Playwright и Android Emulator перед обычной публикацией.
- Отсутствие визуального мерцания на физическом Honor V2 / Android 16 окончательно подтверждается только повторной записью экрана после обновления. Успешный CI не заменяет аппаратную проверку.

## Версия и установка
- `versionName 0.15.6`, `versionCode 41`. Один подписанный APK для телефона и Android Auto.
- Обычный GitHub Release без Beta/Prerelease, подписывается прежним официальным сертификатом и устанавливается поверх 0.15.5 с сохранением данных.
- Статус «частичное покрытие» для родительских тайлов сохраняется честным, поскольку формат сайта не подтверждает, что все объекты карты представлены.
