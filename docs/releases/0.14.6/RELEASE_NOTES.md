# WikiReader Next 0.14.6 — корректное определение геопозиции

## Исправлено
- По кнопке GPS Follow больше не запускаются два независимых запроса местоположения: успешные данные из `watchPosition` больше не сопровождаются ложной ошибкой от `getCurrentPosition`.
- При получении корректного GPS fix очищается устаревшая плашка об ошибке определения местоположения.
- Разовое действие «Рядом со мной» использует тот же временно подключаемый `watchPosition`, что и работающий GPS Follow. Свежая уже полученная координата может быть переиспользована без сетевых/системных запросов.
- Временный наблюдатель ограничен по времени и снимается при успехе, отказе разрешения или отмене действия. Повторные запросы после выхода приложения не остаются активными.

## Проверки
- Добавлены unit-тесты на успешный fix, временные ошибки, отказ доступа, отмену и позднее получение ID наблюдателя.
- Добавлена браузерная регрессия на отсутствие второго запроса при включении GPS Follow.
- Необходима проверка на физическом Android 16: (1) GPS Follow без ложной плашки, (2) «Рядом со мной» без включённого Follow, (3) права/точность и выход из приложения.

## Установка
- Пакет `org.example.wikimapreader.next` не меняется; штатный GitHub Actions проверяет подпись и SHA-256 перед публикацией.
- Установите официальный подписанный `WikiReader-Next-0.14.6.apk` поверх 0.14.5 после прохождения CI.
- Автомобильная AutoDev остаётся в отдельной ветке и получает независимую тестовую сборку. Android Auto Java GPS при этом не изменяется.
