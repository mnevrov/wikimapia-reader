# WikiReader Next 0.8.0 — исследование карты без лишних переходов

## Что нового
- Быстрый поиск в выдвижной панели поверх карты. Полноэкранный поиск по вкладке сохранён.
- Список уже загруженных объектов видимой области с переходом к карточкам и возвратом обратно.
- Три режима визуальной плотности контуров: автоматический, подробный, спокойный. Настройка сохраняется.
- Экономная отрисовка: при изменении карты и очередной странице API существующие неизменённые полигоны не пересоздаются; объекты вне видимой области убираются из слоя.
- Понятное объяснение частичного покрытия, когда API ещё не вернул все объекты.

## Установка и обновление
APK `WikiReader-Next-0.8.0.apk` обновляет установленную 0.7.3 при совпадении постоянного сертификата Next. Не устанавливайте временно подписанные debug APK из Actions поверх стабильной версии. Избранное, кэш и сохранённый API-ключ должны остаться на устройстве.

## Проверки
Публикация выполняется GitHub Actions только после Node/Playwright/Python и Android unit/build/lint. Actions проверяет package ID, versionCode 13, versionName 0.8.0, прежнюю подпись и контрольную сумму APK. Браузерные тесты работают с mock API; это не проверка живого устройства.

## Известные ограничения
- Список видимой области содержит только уже полученные объекты. Неоконченная пагинация Wikimapia означает неполное покрытие.
- Отбор объектов для списка основан на пересечении ограничивающих прямоугольников полигонов; иногда может включить объект за границей обзора.
- Описания, фотографии, комментарии и OSM-подложка по-прежнему требуют сети; офлайн-кэш полных карточек запланирован отдельно.
- Подложка OpenStreetMap пока не следует за темой приложения. Тёмная карта запланирована для следующего этапа.
- Производительность, жесты, TalkBack и поведение на настоящем Android требуют проверки на устройстве.
- Документированный метод `box` помечен deprecated и может измениться независимо от приложения.

Изменения Android Auto (PR #12) в этот выпуск не входят.
