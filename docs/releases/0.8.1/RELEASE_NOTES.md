# WikiReader Next 0.8.1 — единая кнопка загрузки

## Изменения
- Вместо двух похожих кнопок обновления и догрузки на карте показывается одна контекстная кнопка.
- Для полной области она выполняет обновление, при частичной загрузке — продолжает пагинацию, при ошибке — повторяет нужную операцию.
- При загрузке показывается анимация, повторное нажатие блокируется.
- В панели «Объекты в области» сохранена отдельная возможность «Обновить область с сервера», включая неполные области.
- В списке области отображается прогресс в количестве загруженных объектов и общем числе при наличии данных API.
- Дополнены браузерные регрессионные проверки состояний кнопки, обновления и ошибок.

## Обновление
APK `WikiReader-Next-0.8.1.apk` устанавливается поверх прежней версии Next с тем же сертификатом. Сохранённые избранное, кэш и API-ключ не меняются намеренно.

## Проверки и ограничения
GitHub Actions запускает Node, Python, Playwright (mock API) и Android unit/build/lint. Фактические результаты и проверка подписанного APK — на странице сборки релиза.
Тесты с mock API не подтверждают производительность, TalkBack и работу реального устройства.
Android Auto остаётся изолированным в PR #12 и в этот выпуск не включён.
