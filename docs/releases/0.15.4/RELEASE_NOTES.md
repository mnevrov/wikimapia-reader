# WikiReader Next 0.15.4 — диагностика и устойчивое декодирование Wikimapia

## Причина обновления
После публикации 0.15.3 на реальном Android 16 получен обезличенный отчёт: 6/6 запросов к сайту Wikimapia вернули HTTP 200, но 6/6 тайлов завершились ошибкой парсинга; кнопка обновления сработала (pressed=1, started=1). Значит, предыдущая проблема запуска обновления устранена, однако формат ответа сайта на конкретном устройстве не подтверждён.

## Исправления
- Разделён успешный HTTP-ответ и корректно декодированные контуры. Диагностика schema 3 теперь показывает `tileParseReasons` (html/header/rows/empty/body/unknown) и `tileDecode` (complete/partial), не сохраняя тела ответов, координаты, URL или ключи.
- Сайт, вернувший HTML или другой формат с HTTP 200, больше не выглядит как успешная загрузка контуров: приложение отображает ясное сообщение о несоответствии ответа данным тайлов.
- Если отдельная строка .xy имеет некорректную геометрию, валидные объекты того же тайла сохраняются, а покрытие области помечается неполным. Полностью повреждённые тайлы продолжают отвергаться.
- Допущены UTF-8 BOM и CRLF в валидных данных; частичный тайл никогда не превращается в «полный» при повторном чтении из кэша.
- В настройках пояснено различие между HTTP 200 и декодированием.
- Лимиты запросов, HTTPS, обработка 403/429, защита персональных данных и сценарии отмены сохранены.

## Проверки
- Новые тесты ошибочного HTML/header, полностью и частично повреждённых строк, частичного кэша, диагностических категорий.
- Стандартный CI: Node/Python, Playwright, Gradle unit/lint/assemble и Android emulator; релиз допускается только после успеха этих этапов.
- Причина конкретных 6 ошибок на Honor V2 пока не доказана: новый отчёт позволит отделить замену .xy на HTML от повреждённых строк. Физический телефон и работа на сети владельца в CI не тестируются.

## Обновление
- Один APK для телефона и Android Auto; `org.example.wikimapreader.next`, `versionName 0.15.4`, `versionCode 39`.
- Обычный подписанный GitHub Release с прежним сертификатом, совместимый с официальным APK 0.15.3; данные пользователя сохраняются при штатном обновлении.

## Известные ограничения
- Если сервер вместо геоданных отдаёт HTML-страницу доступа, декодер не сможет получить контуры. Не обходить серверные ограничения, антибот-проверки или квоты; использовать только предусмотренные источники, при наличии личного API-ключа действует резервный API.
- Автомобильный нативный декодер не менялся; аппаратная приёмка Android Auto на Honor V2/Android 16 остаётся открытой (issues #42, #51).
- Релиз не подтверждает исправление на физическом телефоне без новой диагностики; не маркируется Beta/Prerelease.
