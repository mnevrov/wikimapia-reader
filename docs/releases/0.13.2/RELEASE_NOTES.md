# WikiReader Next 0.13.2 — ошибки карты в верхней части экрана

## Что изменилось

- Предупреждения и ошибки на карте, включая «Местоположение недоступно», недостаточную точность GPS, сетевые тайм-ауты и отказ API, показываются **сверху слева** компактной плашкой вместо нижнего угла.
- На Яндекс-подложке плашка начинается ниже верхней области служебных элементов картографического SDK, не заходит на правую панель кнопок и не перекрывает юридическую информацию. Элементы Яндекс SDK не меняются.
- При одновременном предупреждении об отсутствии интернета предупреждение об ошибке появляется ниже него.
- В отличие от ошибок, обычные состояния «Загружаем объекты…» и рекомендации вроде «Приблизьте карту» остаются снизу. Краткие сообщения о действиях и отмене удаления по-прежнему имеют приоритет.

## Совместимость и ограничения

- Изменения только в UI и тестах, без смены методов, URL, квот или транспорта Wikimapia API.
- Без VPN ранее наблюдались сетевые тайм-ауты API, через VPN — серверный код `1004`. Эти ограничения не исправляются переносом уведомления, см. [Issue #16](https://github.com/mnevrov/wikimapia-reader/issues/16).
- Версия Android: `0.13.2`, `versionCode 27`; пакет и релизная подпись те же, что в официальной 0.13.1. Пользовательские данные и форматы хранилищ не меняются.
- Диагностический PR #32 и Android Auto PR #12 в выпуск не входят.

## Проверки

- Unit-тесты классификации сообщений: ошибка наверху, обычный прогресс внизу.
- Playwright: позиция в portrait/landscape, отсутствие пересечений с панелью карты и юридическими элементами Яндекса.
- Основной CI: Node, Python, Playwright, Android unit, APK build и lint. Реальное устройство требуется для финальной визуальной оценки.

## Установка

Скачайте подписанный `WikiReader-Next-0.13.2.apk` на [странице релиза](https://github.com/mnevrov/wikimapia-reader/releases) после публикации, установите поверх 0.13.1, сверьте `SHA256SUMS.txt`. APK из PR/CI не следует устанавливать вместо официальной, так как отладочная подпись может отличаться.
