# WikiReader Next 0.15.3 — восстановление загрузки объектов Wikimapia

## Исправления
- Ручное обновление области теперь обходит чтение постоянного кэша, чтобы зависший IndexedDB/Android storage не блокировал запуск сетевого запроса.
- Обычная автоматическая загрузка ограничивает ожидание чтения кэша двумя секундами и при ошибке переходит к сети; повторные проблемы кэша временно не блокируют подгрузку.
- Кнопка обновления не зависит от потенциально устаревшего состояния активности Android WebView. Фоновая автозагрузка по-прежнему следует жизненному циклу Android.
- При нажатии выводится сообщение «Обновляем объекты…» до выполнения запроса.
- Диагностический отчёт schema 2 дополнен метриками `manualRefresh`, `site` (tiles/place/search) и `siteParseFailures`. Запросы к основному сайту Wikimapia учитываются отдельно от резервного API. Координаты, ключи, URL и сырые ответы не записываются.

## Проверки
- Добавлены Node-тесты зависшего кэша и раздельного учёта обращений к сайту и API.
- Добавлен браузерный регрессионный сценарий на случай ошибочного `document.hidden`.
- Полный набор Node/Python/Playwright, Gradle unit tests, lintDebug, assembleDebug и Android Emulator проверяются штатным GitHub Actions workflow перед публикацией.
- Тестирование на реальном Honor V2 / Android 16 и проверка текущей доступности сайта Wikimapia с устройства пока **не проводились**. Исправление устраняет подтверждённые дефекты в коде, но не доказывает окончательное восстановление для каждой сети.

## Обновление
- Пакет `org.example.wikimapreader.next`, версия `0.15.3`, `versionCode 38`.
- Единый APK для телефона и Android Auto. После успешной штатной публикации он подписывается прежним сертификатом WikiReader Next и устанавливается поверх официальной v0.15.2.
- Настройки, избранное и сохранённые области не удаляются. При проблемах с совместимостью ранее установленных неофициальных debug-сборок экспортируйте данные до переустановки.

## Известные ограничения
- Аппаратная приёмка Android Auto на Honor V2 / Android 16 остаётся незавершённой (issues #42, #51), включая GPS, карточки объектов при движении и оформление подложки Яндекса. Успешный CI не заменяет проверку в автомобиле.
- При реальных HTTP-ограничениях, отказах DNS/VPN или изменении формата публичных Wikimapia itiles слой объектов может оставаться недоступен; новая диагностика помогает определить источник проблемы.
- Канал выпуска — обычный GitHub Release (без Beta/Prerelease); никакие аппаратные проверки не объявляются пройденными без фактического теста.
