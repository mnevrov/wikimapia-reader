# WikiReader Next 0.14.4 — новое оформление WikiReader

## Что изменилось
- Обновлена иконка приложения: контур объекта на карте Wikimapia и геометка вместо шаблонного изображения Android.
- Добавлены адаптивная и монохромная версии иконки Android (в том числе системная тематическая иконка Android 13+).
- Обновлены нативная заставка запуска, SVG-логотип веб-заставки и favicon.
- Добавлены исходники фирменного знака и описание палитры (`docs/BRANDING.md`); в README показан новый знак.
- Название non-debug Android-варианта приведено к WikiReader; версия, публикуемая на GitHub, по-прежнему называется **WikiReader Next** и совместима с предыдущей установкой.

## Совместимость и обновление
- Пакет установки Next остаётся `org.example.wikimapreader.next` и использует прежний сертификат подписи — это обязательно проверяется CI перед публикацией.
- Установите `WikiReader-Next-0.14.4.apk` поверх версии 0.14.3 из GitHub Releases. Если подпись или пакет не совпадают, релизный workflow обязан остановиться.
- Логика карт, данных Wikimapia, GPS Follow, офлайн-библиотеки, комментариев, API-ключа и тем интерфейса не изменена.
- Экспериментальный Android Auto остаётся отдельным проектным вариантом в `feat/android-auto`; в стабильную APK этой версии Android Auto не включён.

## Проверки и ограничения
- Автоматический релиз допускается только после успешного Android CI (Node, Python, Playwright, Gradle test/lint/build и Android website emulator) и проверки подписи, пакета, версии и SHA256.
- Проверка на физическом Honor V2/Android 16 и реальный Android Auto host должны выполняться отдельно; CI их не заменяет.
- Нельзя считать результат демо или mock-проверок подтверждением доступа к Wikimapia во всех сетях.
