# WikiReader Next 0.15.2 — компактные настройки

## Что изменилось
- Пересмотрен экран настроек: самые частые действия («Карта и оформление») доступны без прокрутки длинных объяснений. Остальные разделы идут по практической частоте использования: Android Auto, подключение к Wikimapia, данные и хранение, дополнительные инструменты.
- Параметры подложки телефона, темы, автозагрузки области и плотности контуров объединены в первый блок.
- Ключи Яндекс JavaScript API (телефон) и Tiles API (Android Auto) отделены и раскрываются только при настройке, чтобы исключить путаницу.
- Сокращены повторяющиеся подсказки в кэше, офлайн-хранилище и диагностике. Никаких изменений формата сохранённых значений или способов хранения ключей.
- Улучшена компактность и управляемость на 320/390 px и при увеличенном шрифте. Разделы можно раскрывать нажатием и клавиатурой.
- Подтверждена совместимость с предыдущими сценариями выбора карты, автозагрузки, избранного, офлайн-данных и GPS на уровне автоматических тестов.

## Обновление
- Один APK для телефона и Android Auto, пакет `org.example.wikimapreader.next`.
- Подписан прежним сертификатом WikiReader Next, что позволяет обновление поверх официального APK 0.14.6/0.15.1 при совпадении сертификата. Ранее установленные тестовые/debug APK из GitHub Actions могут требовать предварительного удаления.
- Настройки, ключи и пользовательские данные при обычном совместимом обновлении сохраняются; перед переустановкой рекомендуется экспортировать важные данные.

## Проверки
- GitHub Actions: Node/Python, Playwright с проверкой нового интерфейса и прежних сценариев, Gradle JVM unit tests, assembleDebug, lintDebug, Android emulator без API-ключа.
- Релизная сборка: проверка сертификата (SHA-256 подписанта), пакета, номера версии, совпадения ресурсов, SHA256SUMS.txt и загруженных файлов GitHub Release.

## Известные ограничения
- Отдельная аппаратная приёмка Android Auto на Honor V2 / Android 16 не завершена: GPS Follow, взаимодействие с карточками при движении, отступы интерфейса конкретного автомобиля и атрибуция/ссылка Yandex Tiles API требуют реальной проверки (issues #42, #51).
- Яндекс-подложка в автомобиле использует отдельный Tiles API ключ; JavaScript API телефона не подходит.
- Галерея фотографий в Android Auto открывается через мобильный интерфейс только в разрешённом режиме.
- Не объявлять успешный CI заменой проверки в реальном автомобиле.

**Канал публикации: обычный GitHub Release, не Beta/Prerelease.** Изменение политики выпусков запрошено владельцем 09.11.2026. Непроверенные аппаратные сценарии сохраняются в явных ограничениях, а не маркируются пройденными.
