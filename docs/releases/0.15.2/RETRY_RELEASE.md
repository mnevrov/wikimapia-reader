# Явное разрешение повторного запуска 0.15.2

Повторная публикация требуется после успешного слияния PR #58: SHA `64c434cc5d5d930c0339d3f54f3c1df58cfcff34` прошёл PR-CI, но повторный main-CI не завершился из-за внешних ошибок загрузки Gradle/Kotlin (тайм-аут Gradle wrapper и HTTP 504 для `kotlin-compiler-embeddable:2.2.20`).

**Разрешить повтор публикации той же версии `v0.15.2` только после успешного нового CI на main**. Не поднимать версию приложения, не создавать Beta и не обходить аппаратную/сертификатную/контрольную проверку релиза.

Ограничения:
- если релиз уже опубликован — не пересоздавать и не перезаписывать;
- если для этой версии есть `HOLD_RELEASE.md` — публикация заблокирована;
- только авторизованный CI-run на `main` после успешных тестов/сборки и Android эмулятора;
- тестовые данные и реальная приёмка Android Auto — разные вещи; ограничения остаются в `RELEASE_NOTES.md`.
