# WikiReader Next 0.9.0 — чтение, фотографии и тёмная карта

## Новые возможности
- Полноэкранный режим чтения подлинного текста Wikimapia с настройкой размера букв (сохраняется на устройстве).
- Встроенная галерея фотографий: перелистывание, увеличение, жесты и клавиатура; корректный возврат в карточку.
- Поддержка уменьшенной анимации и системной кнопки «Назад».
- Настраиваемая тёмная подложка на **Яндекс JavaScript API 3.0**, при сохранении Leaflet для контуров, выбора объектов, загрузки/кэша и OSM в качестве резервной подложки.
- Отсутствие вызовов Яндекс геокодирования, поиска, маршрутов, панорам: только картографическая схема. API SDK не загружается, пока пользователь не выберет провайдера, и повторно не инициализируется при открытии карточек.

## Настройка тёмной подложки
1. Подключите отдельный ключ продукта **JavaScript API 3.0** в кабинете https://developer.tech.yandex.ru .
2. Настройте ограничение **HTTP Referer** по документации https://yandex.ru/maps-api/docs/js-api/limit.html .
3. На Android Capacitor WebView фактически используемый Referer может отличаться от браузерного; его нужно подтвердить на устройстве. Локальный адрес WebView часто `https://localhost`, но это не гарантируется.
4. В приложении откройте **Настройки → Подложка карты**, введите ключ JS API 3.0, подтвердите настройку Referer и выберите **Яндекс · тёмная карта**.
5. При ошибке SDK приложение продолжает работу на OSM. В любой момент можно вернуть OSM вручную.

Предоставленные пользователем рабочие ключи не включены в код или APK: публичный клиентский ключ вводится на устройстве и отправляется только Яндекс API после явного выбора.

## Проверки
- Unit tests и Playwright в CI с вымышленными ключами; Android `testDebugUnitTest assembleDebug lintDebug`.
- Проверки реального Android WebView/Referer, доступности Яндекс Карты в сетях российских операторов и TalkBack **не выполнены**. Результат с моками не заменяет эти проверки.
- Подписанный совместимый APK, SHA256SUMS.txt и GitHub Release публикуются после успешного CI. Сборка заменяет WikiReader Next 0.8.1, не затрагивая экспериментальную Android Auto ветку.

## Известные ограничения
- Тёмная карта требует отдельного действующего ключа Яндекс **JS API** и соответствующих лицензии и Referer.
- Вариант подложки — синхронизированный YMap под Leaflet, поэтому при быстрых жестах и в медленной сети возможна небольшая задержка обновления схемы до следующего кадра.
- Фото Wikimapia требуют подключения к сети, а отсутствие фотоданных в API не компенсируется дополнительными запросами к Яндексу.
