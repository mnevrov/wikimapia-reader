# WikiReader Next 0.15.0 — одно приложение для телефона и Android Auto

## Что изменилось
- Один APK, один package `org.example.wikimapreader.next` с телефонным интерфейсом и нативным Android Auto `CarAppService`; вторая APK AutoDev больше не требуется. По решению пользователя перенос данных AutoDev не выполняется — рекомендуется чистая установка.
- Общее защищённое хранилище, настройки и данные для обоих режимов внутри одного пакета. Сохраняется поддержка Wikimapia без API ключа, контуров, карточек, избранного и GPS.
- Автомобильный нативный движок может использовать OSM или официальный Yandex Tiles API. На телефоне JavaScript API Яндекса по-прежнему настраивается отдельно.
- Tiles API ключ вводится только на телефоне, хранится через Android Keystore, не возвращается в WebView и не включается в GitHub/CI. Доступен отдельный выбор автомобильной подложки.
- Яндекс Tiles API: `web_mercator`, `l=map`, `lang=ru_RU`, `scale=2` (512px), до восьми запросов в секунду, ограниченные LRU-кэши, backoff на 403/429, fallback на OSM без бесконечного повторения.
- На экране автомобиля отображается официальный логотип Яндекса с обработчиком нажатия и адресом `https://yandex.ru/maps/`. Переключатель и переход также доступны из шаблона Android Auto.

## Установка и проверка
- Физическая приёмка автомобиля остаётся обязательной: не все автомобильные host доставляют `SurfaceCallback.onClick`. До её подтверждения Яндекс Tiles API и объединённая Auto-функция считаются кандидатом, не завершённой сертификацией.
- Получите отдельный ключ **Yandex Tiles API**, не используйте JS API ключ. В `Настройки → Подложка Android Auto` сохраните его и выберите Яндекс. Без ключа доступна OSM.
- Проверьте оба экрана на Android 16, GPS Follow и панель атрибуции в движении/на стоянке, ссылки, контуры, изменение масштаба, смену темы.
- Условия и логотип: https://yandex.ru/maps-api/docs/tiles-api/index.html.
- Тестовая APK GitHub Actions подписана debug-ключом и **не обновляет** обычную подписанную 0.14.6. Официальный подписанный APK разрешён только после успешного CI и аппаратной приёмки.
