# WikiReader Next 0.10.0 — офлайн-чтение и GPS Follow

## Новое

- Ручное сохранение открытых объектов Wikimapia: полное текстовое описание, комментарии и успешно загруженные фотографии сохраняются в отдельной базе IndexedDB; API-ключи в сохранённые объекты не попадают.
- На экране «Избранное» появился самостоятельный список «Для чтения без сети»: офлайн-копию можно читать, даже если объект не добавлен в избранное или в момент открытия нет действующего API-ключа.
- Фото, загруженные для офлайн-доступа, отображаются в существующей галерее через локальные Blob URL. Недоступные фото не блокируют сохранение описания: показывается состояние «Сохранено частично».
- «Настройки → Офлайн-чтение»: отдельный лимит 25–500 МБ, срок актуальности 7–365 дней, статистика текста и фото, подтверждение полной очистки. Устаревшие карточки сохраняются и помечаются, а не удаляются автоматически.
- GPS Follow: одна кнопка включает и выключает слежение; перемещение карты анимировано, малые изменения координат отфильтровываются. Ручное перетаскивание приостанавливает слежение, следующее нажатие кнопки возобновляет его. При уходе приложения в фон подписка останавливается.
- Для объектов Wikimapia не добавлены недокументированные API, сторонние прокси или тайлы для неразрешённой офлайн-подложки. Минимальный интервал запросов Wikimapia сохранён — 6 секунд.
- Кнопка «Открыть в Яндекс Картах» и официальные обозначения остаются у SDK; не скрываются CSS или модификацией DOM. Позиции элементов WikiReader резервируют пространство вокруг элементов Яндекса.

## Обновление

Установите подписанный `WikiReader-Next-0.10.0.apk` из GitHub Release поверх предыдущей WikiReader Next 0.9.5. Настройки, избранное и отдельный кэш контуров сохраняются. Идентификатор приложения остаётся `org.example.wikimapreader.next`; выпуск должен использовать прежний сертификат подписи. Перед установкой проверьте `SHA256SUMS.txt`.

## Ограничения

- Офлайн-доступность касается **карточек и успешно сохранённых фотографий**, но не Yandex Maps или OpenStreetMap.
- Срок актуальности — индикатор возраста, а не автоматическое удаление выбранных объектов.
- Доступность фотографий зависит от сервера и политики CORS/HTTP; при ошибках фото не сохраняется, текст остаётся доступен.
- GPS Follow работает только при активном приложении и предоставленном разрешении. Фоновая геолокация и гарантии энергопотребления не заявляются.
- Browser/Playwright geolocation и mock-ответы Wikimapia не являются проверкой точности GPS, расхода батареи и доступности CDN на физическом Android.
- Официальный SDK имеет технические опции управления контролами, но условия Яндекс Карт требуют видимости кнопки «Открыть в Картах»: она намеренно не скрывается.

## Подтверждения

Фактические результаты unit, Playwright, Android lint/Gradle, проверки подписанного APK и публикации должны быть проверены по GitHub Actions и GitHub Release. До успешного завершения этих этапов 0.10.0 нельзя считать выпущенной.
