# WikiReader Next 0.14.1 — компактные карточки и даты комментариев

## Изменения

- Убраны два постоянных ряда действий под карточкой. Избранное, закрытие и меню
  «⋯» находятся сверху, название использует всю ширину карточки. В меню —
  «На карте», «Поделиться», сохранение для чтения без сети, разворачивание и переход
  в Wikimapia. Жесты разворачивания и закрытия сохранены.
- В краткой карточке показываются первые пять строк описания; «Читать полностью»
  находится после текста. В развёрнутой карточке описание прокручивается целиком.
- GPS-предупреждение больше не растягивается между верхним и нижним отступами
  при включённой подложке Яндекса. Высота зависит от текста.
- Комментарии показывают дату источника. При наличии ISO-времени отображается
  календарная дата; иначе сохраняется текст сайта, например «18 лет назад».
  Если источник не передал дату, показывается «Дата не указана». Относительная дата
  в сохранённой копии соответствует тексту на момент загрузки, не пересчитывается
  и не превращается в выдуманную точную дату.
- Текст даты сохраняется при офлайн-чтении и переносе резервной копии.

## Проверки

- Регрессионный тест воспроизвёл прежнее GPS-уведомление высотой 606 px.
- Проверяются размеры 320×640, 390×844, 844×390, контент карточки, меню,
  клавиатурный фокус, даты из HTML и их сохранение офлайн/в резервной копии.
- Проверка увеличенного текста в браузере использует увеличенные CSS-шрифты;
  это не проверка системного масштаба на физическом телефоне.
- Независимое ревью: замечание о восстановлении фокуса после команд меню
  исправлено с воспроизводящим тестом.
- Node/Python, полный браузерный набор и Android unit/build/lint проверяются перед
  публикацией; итоговые результаты — в CI выпущенного коммита. Live-проверка
  Android-транспорта сайта также остаётся обязательным условием workflow.

## Установка и ограничения

Версия 0.14.1, Android versionCode 29. Установите `WikiReader-Next-0.14.1.apk`
из GitHub Release поверх официального WikiReader Next. Пакет и постоянный
сертификат Next сохраняются; данные приложения удалять не нужно.

Изменения проверяются в браузере и CI; физический Android и TalkBack отдельно
не проверены. Поддержка даты зависит от разметки сайта. Старые офлайн-копии,
созданные без даты, нужно загрузить заново, чтобы получить отсутствующее поле.
Внутренние маршруты Wikimapia сохраняют ограничения доступности и стабильности,
описанные в выпуске 0.14.0. Функциональность Android Auto не затрагивается.
