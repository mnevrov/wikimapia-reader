# WikiReader Next 0.9.4 — безопасное оформление атрибуции Яндекс Карт

## Что изменилось
- Глобальные CSS-правила WikiReader больше не переопределяют кнопки, ссылки и другие HTML-элементы, созданные внутри Яндекс JavaScript API 3.0. Это позволяет SDK самостоятельно задавать размер, оформление и контраст официальных обозначений.
- Сообщение о состоянии области WikiReader перенесено из левого нижнего угла в верхний левый при выбранной Яндекс-подложке. При сетевом предупреждении сообщение сдвигается ниже него.
- Всплывающие уведомления WikiReader теперь показываются выше нижней зоны атрибуции Яндекса.
- Официальная кнопка «Открыть в Картах», логотип, авторские права и юридические ссылки самого SDK не изменяются, не уменьшаются и не скрываются.
- Контуры Wikimapia, жесты, выбор карты, хранение ключа, светлая/тёмная темы и OSM остаются без изменений.

## Проверки
- Мок-тест в Playwright удостоверяет, что штатные ссылки и кнопки SDK не получают стили WikiReader, что служебный статус не накладывается на нижний угол с атрибуцией, а OSM-подложка сохраняет копирайт.
- GitHub Actions собирает Android с полным набором браузерных тестов, JVM-тестами и lint. Подписанный релиз проверяется по контрольной сумме SHA256.
- Физический Android WebView с настоящими элементами Yandex JS API **не протестирован** в этой версии. Особенно требуется подтвердить не только видимость, но и работу кнопки «Открыть в Картах» при наличии Leaflet поверх подложки. Мок-тест не доказывает её кликабельность.

## Обновление
Установите подписанный `WikiReader-Next-0.9.4.apk` из GitHub Releases поверх 0.9.3. Настройки и ключи сохраняются; новый Яндекс-ключ не требуется.
