# WikiReader Next 0.13.1 — компактные уведомления и GPS Follow

## Что изменилось
- **Статусы карты** теперь отображаются небольшим сообщением у **нижнего левого края**, выше зоны атрибуции и нижней навигации. В том числе на подложке Яндекс Карт статус больше не находится посреди карты и не перекрывает официальные элементы SDK.
- При слабом GPS-сигнале предупреждение показывается один раз, исчезает через пять секунд и не остаётся над картой постоянно. Новая попытка GPS Follow может снова показать предупреждение.
- Если одновременно появляется короткое подтверждение действия или кнопка отмены удаления из избранного, **временное уведомление имеет приоритет**, а фоновый статус карты на это время скрывается. После исчезновения временного уведомления статус карты снова виден.
- Исправлена логическая ошибка: включение **GPS Follow больше не ставит загрузку областей на паузу**. Механизм загрузки продолжает работать при обновлении координат, если API доступен.
- Номер версии в разделе «Настройки» теперь берётся из `package.json`, чтобы не показывать устаревшее 0.11.1.

## Что осталось без изменений
- **Сетевой доступ к `api.wikimapia.org` и серверная ошибка ключа `1004` НЕ исправлены.** Без доступного сетевого маршрута и разрешённого ключа новые данные от Wikimapia не появятся. Исследование: [Issue #16](https://github.com/mnevrov/wikimapia-reader/issues/16).
- Не менялись `src/client.js`, HTTP-транспорт, URL сервера, интервал API-запросов и обработка квоты.
- Исправления диагностического PR #32 не входят в этот выпуск; Android Auto PR #12 по требованию пользователя остаётся отдельным и не изменяется.
- Форматы офлайн-кэша, избранного, истории, резервных копий и ключей Android Keystore не изменялись.

## Установка
Установите подписанный `WikiReader-Next-0.13.1.apk` из [GitHub Releases](https://github.com/mnevrov/wikimapia-reader/releases) поверх 0.13.0. Android `versionCode 26`; пакет и ключ подписи **те же**, что у официального 0.13.0. Скачайте и сверьте `SHA256SUMS.txt`. GitHub Actions debug APK может иметь несовместимую подпись и **не** является заменой релизному APK.

## Проверки
- Браузерные тесты (Playwright): GPS Follow и загрузка следующей области на заглушке API; геометрическое положение статуса на портретном и альбомном экране, отсутствие пересечения с панелью кнопок и навигацией; приоритет временного toast/undo; защита официальных элементов Яндекс Карт.
- Node/Python offline tests, Gradle `testDebugUnitTest`, `assembleDebug`, `lintDebug` — GitHub Actions.
- Проверки на физическом Android: **требуются после установки** для реального поведения GPS, системных отступов и разных дисплеев. Проверки внешнего Wikimapia API не являются критерием успешности UX-изменений этого релиза.
