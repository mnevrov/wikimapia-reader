# WikiReader Next 0.9.1 — Яндекс Карты следуют теме оформления

## Исправлено
- Яндекс-подложка выбирает **ночной стиль** для чёрной темы WikiReader и **дневной стиль** для светлой темы.
- В режиме **«Как в системе»** цвета подложки изменяются вместе с системной темой, в том числе без перезапуска приложения.
- При инициализации цвет явно задаётся и карте `YMap`, и её слою `YMapDefaultSchemeLayer`. При переключении обновляются оба объекта — без повторного создания карты, дополнительных подключений SDK и сброса положения/контуров Wikimapia.
- В настройках нейтральное название **«Яндекс Карты»** вместо «Яндекс · тёмная карта». Источник доступен и при светлом оформлении.
- Ранее сохранённый выбор подложки, пользовательский JS API-ключ, кэш и избранное сохраняются.

## Установка
Скачать `WikiReader-Next-0.9.1.apk` из GitHub Release и установить поверх 0.9.0. Подпись совместима с другими выпусками Next. Из старой версии 0.4 приложение не обновляется автоматически.

## Проверки и ограничения
- Проверяются переходы **чёрная → светлая → чёрная**, начальная загрузка светлой карты и **системная светлая ↔ тёмная** на имитации JavaScript API 3.0 в Playwright. Проверяется, что SDK загружен один раз, а `YMap` и `YMapDefaultSchemeLayer` получают одинаковые темы.
- CI также запускает модульные тесты, браузерные регрессии и Android `testDebugUnitTest assembleDebug lintDebug`. Фактический результат виден в GitHub Actions и не предполагается заранее.
- Реальная проверка цвета схемы на устройстве Android WebView, действительного `HTTP Referer`, российских мобильных сетей и TalkBack **не проводилась**. Для Яндекс-карты по-прежнему требуется отдельный ключ **JavaScript API 3.0**, правильно ограниченный по Referer, и соблюдение условий бесплатной лицензии.
- Геокодирование, панорамы, маршруты, поиск организаций Яндекса не вызываются. При сбое Яндекса остаётся резервная OSM-подложка.
- Android Auto не изменялся и не сливался.
