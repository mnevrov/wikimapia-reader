# WikiReader Next 0.14.0 — чтение без обязательного API-ключа

Реальная карта открывается сразу. Контуры, описание карточки, фотографии и комментарии
читаются с сайта Wikimapia. Деморежим теперь включается только явно в настройках.

Личный API-ключ необязателен. Если он добавлен, сайт остаётся приоритетным, а API
дополняет недоступные данные. Удаление ключа сохраняет избранное, историю, кэш и офлайн-копии.

## Поведение

- Поиск сайта показывает места на карте: нажмите результат, затем выберите контур.
  Открытие по ID и ссылке работает напрямую. При недоступности поиска сайта используется API,
  если добавлен ключ; без ключа остаются ID/ссылки и поиск по локальной библиотеке.
- Незнакомая разметка, частичная карточка и ошибка RK n.22 не маскируются сообщением
  «данных нет». Доступные блоки сохраняются; ограничения видны и в офлайн-копии.
- При дополнении области через API контуры сайта сохраняют приоритет на всех страницах.
- Форматы контуров декодируются отдельно; частичное покрытие не маркируется полным.
- Ограничения доступа 403/429 останавливают автоповторы. Ключ не отправляется на сайт или фото.
- Сохранены режим чтения, галерея, избранное, история, резервные копии, темы и GPS Follow.

## Проверки

- 128 Node и 9 Python тестов PASS после исправлений независимого ревью.
- Новые браузерные сценарии: без ключа, с ключом без расходования API на полную карточку,
  удаление ключа с сохранением избранного, частичная офлайн-копия, скрытые комментарии,
  неизвестная разметка и безопасность парсинга.
- Живой сохранённый тайл: 2920 контуров разобраны; Java-транспорт получил реальную
  карточку №350 без ключа (описание, 7 фото, 16 комментариев).
- Полный браузерный набор, Android unit/build/lint и live-проверка на Android-эмуляторе
  являются обязательными воротами CI перед публикацией. Их итог следует смотреть
  в workflow выпущенного коммита; незавершённый запуск не является PASS.

## Обновление и ограничения

Версия Android: 0.14.0, versionCode 28. Скачайте `WikiReader-Next-0.14.0.apk` и
`SHA256SUMS.txt` из GitHub Release и установите поверх предыдущего официального Next.
Пакет и постоянный сертификат не меняются. APK обычного PR/runner не является
совместимым подписанным обновлением.

HTML и itiles — внутренние форматы сайта, без гарантий стабильности, полноты и квот.
Доступность на физическом телефоне и из РФ отдельно не подтверждена. Браузерный preview
может ограничиваться CORS; основной целевой вариант — Android с нативным HTTPS-транспортом.
Проверка эмулятора не заменяет физическое устройство. Атрибуция Wikimapia сохраняется;
безлимитный доступ не обещается. Android Auto из отдельной ветки в этот выпуск не входит.
