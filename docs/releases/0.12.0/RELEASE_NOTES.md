# WikiReader Next 0.12.0 — история чтения и единая библиотека

## Что нового
- История **50 последних успешно открытых реальных объектов** Wikimapia: быстрый возврат из вкладки «Избранное». При повторном просмотре объект перемещается в начало списка.
- Единый локальный поиск по избранному, недавно просмотренным объектам, сохранённым для офлайн-чтения карточкам, включая полный текст **сохранённых** описаний, и ID.
- Историю можно отключить, удалить отдельный просмотр либо полностью очистить с явным подтверждением. Отключение очищает историю автоматически.
- В истории сохраняются только ID, короткое название и время просмотра. Демо, неудачные загрузки, ключи, координаты и описания в историю не попадают.
- История и поиск не инициируют дополнительных запросов к Wikimapia. Просмотр истории требует сети, если карточка отдельно не сохранена для офлайн-чтения.

## Обновление
Установите WikiReader-Next-0.12.0.apk поверх 0.11.1 из GitHub Release.
Приложение сохраняет `org.example.wikimapreader.next`, прежнюю подпись, избранное, IndexedDB офлайн-карточек и кэш областей. Версия Android: 0.12.0, versionCode 24.
Сверьте хеш APK с `SHA256SUMS.txt`. Не устанавливайте временный debug APK из CI поверх рабочей версии.

## Проверки
Предусмотрены Node unit tests, Playwright browser tests (с синтетическим Wikimapia API), Python offline tests и GitHub Actions Android test/lint/assemble, проверка сертификата и SHA256 на стадии публикации.
Фактические результаты и ссылки на успешные CI должны быть подтверждены до публикации; до тех пор считать эту ветку кандидатом.

## Ограничения
- Проверка на физическом Android (включая TalkBack, WebView, автономный запуск и производительность): NOT_RUN до ручной проверки.
- Живой Wikimapia API с личным ключом: NOT_RUN. Используются существующие официальные методы и ограничение >=6 секунд между запросами.
- История хранится только на данном устройстве, не синхронизируется и исчезает при очистке данных приложения.
- Полнотекстовый поиск охватывает только **явно сохранённые офлайн-карточки**; он не ищет по интернету и не индексирует все объекты карты.
- Android Auto остаётся в отдельном PR #12, не включён в 0.12.0.
