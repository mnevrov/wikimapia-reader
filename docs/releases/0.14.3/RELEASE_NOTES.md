# WikiReader Next 0.14.3 — безопасная диагностика резервного API

## Изменения
- Перенесена диагностическая функция PR #32 на актуальную site-first архитектуру 0.14.2, без старой конфигурации debug-пакета.
- Настройки → Диагностика Wikimapia: только на Android и только при добровольно добавленном ключе доступен ручной A/B-тест Android Native HTTP / WebView. Сайт продолжает работать без ключа.
- Проверка выполняет максимум два запроса к официальному API, прекращает проверку после auth/quota, соблюдает общий интервал 6 секунд между API-вызовами и не меняет production timeout.
- Отчёт содержит только категории результатов, длительность, HTTP-код, числа объектов/контуров и явно разрешённый код API 1004. Не включает ключ, URL, координаты, данные объектов или сырой ответ.
- Добавлены модульные и Playwright-регрессии, инструкция ручной проверки и тест конфиденциальности.

## Проверки и ограничения
- Node, Python, Playwright, Gradle, Android emulator и release signing проверяются GitHub Actions; итог смотрите в релизном workflow.
- Успешный CI с mock API НЕ доказывает доступность резервного API из любой мобильной сети. На устройстве ранее наблюдался timeout без VPN и ответ 1004 через VPN (см. #16).
- Верификация реальных контуров и карточек на физическом Android остаётся незавершённой и контролируется Issue #16.
- Android Auto (#12) не изменён.
- Установите `WikiReader-Next-0.14.3.apk` из GitHub Releases поверх 0.14.2; прежние package ID и сертификат подписи сохраняются.
