# WikiReader Next 0.14.5 — стабильная загрузка контуров Wikimapia

## Исправлено
- Контуры Wikimapia больше не ограничиваются первыми 16 тайлами постоянного уровня z15: клиент выбирает максимально подробный уровень, который позволяет покрыть всю видимую область в пределах лимита 16 тайлов.
- При отдельной ошибке сайта ранее успешно полученные контуры сохраняются; неполное покрытие не считается полным, а отсутствие всех удачных запросов остаётся ошибкой.
- Продолжают соблюдаться квоты, безопасный предел области и ограничения источника. Внутренние уровни детализации сайта могут оставаться неполными.

## Проверено
- Node, Python, браузерные и Android CI из PR #44.
- На физическом Android пользователь подтвердил, что ранее воспроизводимая пропажа контуров при смене масштаба устранена.
- Независимые проверки Android Auto, GPS в машине и наличия Яндекс-подложки в AA к этому мобильному релизу не относятся.

## Обновление
- Релиз сохраняет пакет `org.example.wikimapreader.next` и установленную схему подписи; GitHub Actions проверяет это до публикации.
- Установите подписанный `WikiReader-Next-0.14.5.apk` поверх официальной 0.14.4 из GitHub Releases после успешных проверок.
- Тестовый Android Auto кандидат разрабатывается отдельно, `feat/android-auto`, и не включается в мобильный релиз.
