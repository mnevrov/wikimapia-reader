# WikiReader Next 0.9.5 — разнесение элементов Яндекс Карт

## Исправление

- Официальный логотип/блок распространения Яндекса размещён в правом верхнем углу через поддерживаемый параметр `distributionPosition` JS API 3.0; копирайт — справа внизу через `copyrightsPosition`.
- Шесть кнопок управления WikiReader в режиме Яндекса подняты над нижним углом с копирайтом. На низких горизонтальных экранах они перестраиваются в две колонки.
- Сетевые сообщения и статусы области сдвинуты ниже логотипа, чтобы не перекрывать его. В режиме OSM расположение не меняется.
- Логотипы, ссылки, размеры, прозрачность и сами элементы SDK не модифицируются. Ключи и лишние запросы к API не добавляются.

## Проверки и ограничения

- Playwright с мок-версией SDK проверяет расположение официальных блоков, отсутствие пересечений с кнопками и уведомлениями в портретной и альбомной ориентациях, сохранение стилей SDK и возврат атрибуции OSM.
- Реальный Android WebView и живой Yandex SDK в CI не тестируются: точная раскладка SDK на устройстве и кликабельность его ссылок под прозрачной интерактивной картой Leaflet требуют отдельного теста на телефоне. Мок-тест не доказывает соблюдение всех требований Яндекса в реальной сборке.

## Обновление

Установите подписанный `WikiReader-Next-0.9.5.apk` из GitHub Releases поверх предыдущей версии после публикации релиза. Настройки и API-ключи сохраняются.
