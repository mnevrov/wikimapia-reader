# Проверки версии 0.3.0

18.10.2026. Чёрная тема прошла 18 Node-тестов, 3 теста валидации Python-пробника
и 7 браузерных сценариев Chromium (390×844, mock API/тайлы).

Подтверждены: чёрное оформление по умолчанию, сохранение светлой/чёрной темы,
реакция системного режима без перезагрузки, читаемое поле ключа, работа карточек
и доступ к настройкам поверх открытой карточки.

Чистая сборка `assembleDebug` и `lintDebug`: exit 0. Проверены подпись APK,
версия 0.3.0/code 3, совпадение web assets с dist, наличие AppearancePlugin в DEX
и раннего чёрного backgroundColor в упакованной конфигурации.

APK подписан тем же ключом, что выданная здесь версия 0.2.0, и рассчитан на установку
поверх неё. Сам ключ подписи не включён в репозиторий. Машиночитаемые результаты
и SHA-256 — `theme-checks.json`.

Независимый read-only ревьюер нашёл светлое поле ключа и возможную белую вспышку
WebView. Оба дефекта исправлены и перепроверены. Новый browser-тест сначала
воспроизвёл белое поле, после исправления полный набор прошёл. Дополнительно
существующий тест обнаружил перекрытие настроек карточкой после добавления
переключателя темы; настройки подняты выше карточки, повторный тест прошёл.

Новую нативную версию на физическом устройстве разработчик не запускал.
Предыдущую 0.2.0 пользователь установил и подтвердил её работу. Для 0.3.0 нужно
проверить системные панели и жестовую навигацию, смену темы и холодный старт.
Подложка OpenStreetMap сохраняет исходные цвета.
