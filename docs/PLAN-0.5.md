# Версия 0.5: сохранённый ключ и понятная навигация

Поручение: сохранять ключ в Android, не заставлять вводить его при каждом запуске; переработать интерфейс целиком. Работа выполняется автономно в feature-ветке.

- [x] AndroidKeyStore AES256GCM: ciphertext в приватном SharedPreferences, новый nonce при каждой записи, AAD/проверка целостности, backup/transfer excluded.
- [x] Восстановление до загрузки карты; изменение/удаление с явным результатом; без plaintext fallback в браузере.
- [x] Навигация карта / поиск / избранное / настройки. Карточка с режимом чтения, датами и жестом раскрытия. Подключение ключа отдельно от поиска.
- [x] Избранное source+id, миграция прежних IDs, исключение пересечения demo/реальных объектов.
- [x] Независимое read-only ревью; исправление ошибки раскрытия URL ключа через diagnosticError и контраста светлых кнопок.
- [x] Node32, Python3, JVMcrypto3, Chromium21 — повторные прогоны PASS.
- [x] Настроен Native CI build/lint/unit tests. Выпуск APK требует успешной проверки CI, проверки подписи и сохранения developer keystore отдельно от git.

Решение по подписи: старый локальный debug keystore не сохранился вместе с предыдущими исходниками. Выпуск debug applicationId org.example.wikimapreader.next с именем WikiReader Next позволяет установить версию рядом с 0.4 и сохранить старые данные. Новый developer keystore сохраняется отдельно от git для последующих обновлений этой сборки. Ключ Wikimapia не встраивается в APK.
