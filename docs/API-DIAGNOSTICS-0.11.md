# Диагностика Wikimapia API (0.11.1)

## Что сохраняется

В настройках WikiReader Next доступен блок **«Диагностика Wikimapia»**.
Приложение в оперативной памяти подсчитывает только число запросов по фиксированным
методам, среднюю длительность HTTP-запроса, категории ошибок и агрегированную полноту
загрузок областей. Записи исчезают после закрытия процесса либо по кнопке «Очистить».
Ключи, координаты, bbox, идентификаторы, поисковые строки, тела ответа и исходные тексты
ошибок никогда не попадают в отчёт. Передача возможна только при ручном копировании.

Категория `cancelled` означает сознательную отмену: она не считается тайм-аутом
и не провоцирует автоповтор. Ошибки `quota`, `auth`, `schema` не повторяются
автоматически. Сохраняется минимум 6 секунд между началом запросов.

## Сравнение документированных методов

[Официальная документация](https://wikimapia.org/api) указывает современный
`place.getbyarea` вместо устаревшего `box`, но наличие метода в документации
не гарантирует пригодность ответа. Предыдущие запросы через общий примерный ключ
давали `[]` для `place.getbyarea`; форма неоднозначная. В текущем клиенте
`box` оставлен действующим источником, автоматическое переключение отключено.

Для **ручной** проверки на компьютере (не в CI), из корня репозитория:

```bash
python3 scripts/probe_compare.py --ask-key --out /tmp/wikimapia-area-compare.json
```

Также допустимы `--example` и переменная окружения `WIKIMAPIA_API_KEY`;
не записывайте ключ в командную строку, CI или issue. Скрипт использует фиксированный
тестовый bbox, вызывает только официальные HTTPS-методы последовательно с интервалом
не менее 6 секунд между началом запросов, пишет лишь безопасные агрегаты.

Положительный результат обеих проверок — сигнал для более широкого тестирования,
но **не** основание автоматически менять production-метод. Требуется реальный
Android smoke-test с личным ключом и проверки схемы, пагинации, полноты контуров,
квот и корректности при нестабильной сети. Оба результата должны подтверждаться
живыми данными, а не только синтетическими fixtures.
