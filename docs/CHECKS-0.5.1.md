# WikiReader Next 0.5.1 — автозагрузка и кэш областей

## Причины проблемы

В 0.5 запрос не выполнялся при zoom < 16, даже если видимая область укладывалась
в допустимые границы. Начало загрузки очищало контуры, точное сравнение bbox
делало кэш бесполезным при небольшом движении, а первая ошибка блокировала
автозагрузку до ручного обновления. Постоянный счётчик дублировал число объектов.

## Изменения

- Убрано ограничение zoom 16; сохранён предел стороны запроса 0.035°.
  При слишком широком обзоре остаётся понятная подсказка приблизить карту.
- После остановки карты задержка 250 мс. Границы запроса расширяются на 20%
  с каждой стороны, пока это позволяет предел размера. Это один официальный
  `box`, без внутренних тайлов Wikimapia и сторонних прокси.
- Кэш проверяет покрытие видимой области, а не точное совпадение bbox.
  Контуры пересекающихся областей остаются на карте во время обновления.
- До трёх страниц загружаются автоматически, дальше — «Показать ещё объекты».
  Повторённая/пустая страница останавливает пагинацию; объекты объединяются по ID.
- Временный сетевой сбой повторяется через 8 секунд, максимум два раза.
  Повторяется именно неудачная страница. Ошибка ключа/квоты/структуры ответа
  не вызывает автоматических повторов. Ручное обновление позволяет повторить запрос.
- Старые ответы отбрасываются; в фоне и при открытой карточке загрузка приостановлена.
- Большая сводка с количеством объектов удалена. Остались небольшие сообщения
  загрузки, ошибки, пустой области и подсказка масштаба.
- Частота запросов осталась не чаще одного старта за 6 секунд для всех методов.
  Новые области не гарантированно появляются мгновенно: влияют сеть и очередь API.

## Постоянный кэш

IndexedDB `wikireader-areas`, объектное хранилище `areas`, в данных приложения.
Сохраняются bbox, timestamp, ID, название, координаты и состояние пагинации.
API-ключ, URL запросов, комментарии и фотографии в кэш не попадают.
Кэш публичных контуров общий для ключей на этом устройстве; он не является хранилищем credentials.

Ограничения: 32 области, суммарно 12 МиБ сериализованных записей, срок 24 часа.
Самые старые записи вытесняются. До 5 минут область используется без сети;
более старые контуры показываются во время запроса свежих данных. По истечении
суток записи удаляются при следующем чтении/записи кэша и не используются.
Размер файлов самой IndexedDB с её накладными расходами может отличаться от 12 МиБ.

Очистка — «Настройки → Кэш областей → Очистить кэш областей».
Записи и очистка сериализованы, память загрузчика сбрасывается. Ошибка хранилища
не мешает сетевому режиму; сообщение очистки не выдаётся при неудаче.
Кэш не включает подложку OSM и карточки: полностью автономный режим не заявляется.

## Проверки

- Node: проверка покрытия, TTL, дискового восстановления, старых ответов,
  удержания контуров, ошибок диска, приоритета свежих записей, лимитов размера/числа
  и отсутствия посторонних полей. Отдельно проверено повторное чтение с диска после вытеснения области из памяти. Вместе с прежними проверками — 42 теста.
- Python: 3 offline-проверки валидатора probe.
- Playwright Chromium: 29 тестов, включая zoom 15 + pan, автопагинацию,
  временную ошибку + pan, reload + сохранённый кэш, очистку,
  устаревший кэш без сети, отсутствие ключа в IndexedDB и ограниченные повторы page 2.
  Остальные сценарии: ключ, поиск, избранное, комментарии, фон, темы и размеры экрана.
- Vite build и Capacitor sync выполняются перед Android-сборкой.
- GitHub CI выполняет Node, Python, Playwright, JVM testDebugUnitTest,
  assembleDebug и lintDebug. Итоговый статус и APK сверяются после выполнения CI.

Браузерные проверки используют mock API/тайлов/native bridge. Они проверяют
логику приложения, но не скорость реального сервиса. Личный ключ пользователя
не использовался в тестах, логах, git или CI. Физический Android/WebView с новым
кэшем, аппаратный Keystore и время ответа Wikimapia на телефоне — NOT_RUN.

## Независимое ревью

Три P2 найдены и исправлены: цикл повторов при отказе второй страницы;
обратный приоритет восстановленных записей; погрешность bbox ровно 0.035°.
Добавлены регрессии; повторное read-only ревью не выявило новых блокирующих проблем.

## Установка

Версия 0.5.1, versionCode 6, package `org.example.wikimapreader.next`.
Передаваемый APK переподписывается тем же сохранённым ключом Next, что версия 0.5.0.
Это позволяет обновление с сохранением данных. Сырой артефакт CI использует ключ
временного runner: напрямую поверх переданного Next его устанавливать не следует.
