# WikiReader Next 0.7.3 / code12 — жест карточки

Причины резкого закрытия: обработка только pointerup без движения панели,
а также visibility:hidden родительской карты при возврате в поиск/избранное.

Ручка теперь захватывает pointer; карточка следует за вертикальным движением.
Свёрнутая карточка уходит вниз, а движение вверх раскрывает её. Развёрнутая
карточка при движении вниз меняет высоту, затем фиксируется в свёрнутом состоянии.
Короткое движение возвращается к исходному состоянию. Достаточное расстояние
или быстрый направленный вниз жест закрывает свёрнутую карточку.
Выход начинается с фактического transform, без возврата в нулевое положение.
Возврат/фиксация — 280 мс; reduced motion исключает автоматическое движение.
Отмена pointer и уход в фон завершают/сбрасывают незавершённый жест.
Перетаскивание ограничено ручкой, чтобы сохранить обычную прокрутку текста/фото.

Проверены аналогичные места: ObjectChooser использует Motion; Disclosure сохраняет
контент на выходе; главный экран больше не скрывает выходящую карточку.
Других обработчиков pointerup с пороговым изменением панели нет.
Паттерн partial/expanded/settling/hide сверялся с документацией Android:
https://developer.android.com/develop/ui/compose/components/bottom-sheets-partial
https://github.com/material-components/material-components-android/blob/master/docs/components/BottomSheet.md

Регрессии проверяют движение до отпускания, возврат короткого жеста, непрерывность
выхода, сворачивание развёрнутой карточки, pointercancel, видимость при возврате
в поиск, touch через Chromium CDP, прокрутку текста и reduced motion.
До исправления два теста движения падали; после исправления выполняется полный
набор браузерных тестов и Android CI. Итоги/ссылка CI/SHA256 фиксируются в PR.

В браузере API/tiles/native bridge подменены. Физический Android, FPS и TalkBack
— NOT_RUN. Браузерные жесты не доказывают плавность на конкретном телефоне.
APK подписывается прежним сертификатом Next для установки поверх 0.7.2.
