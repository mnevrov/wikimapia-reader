# Android Auto — WikiReader Next 0.14.4

**Изолированный кандидат AutoDev. Не сливать в main до отдельной аппаратной приёмки.**

Сохранена нативная реализация PR #12. После обновления базы 0.14.2 (React/Capacitor/Leaflet) нативная автомобильная поверхность использует website-first `CarSiteSource`: контуры с публичных itiles, короткие карточки из HTML, поиск по имени с перемещением карты, поиск по ID/ссылке. Личный API-ключ **необязателен**. Если сайт не даёт пригодный ответ, существующий legacy API может дополнить данные **только при наличии ключа**, а ошибки или квота не скрываются.

Используются только публичные HTTPS-ресурсы Wikimapia, без сторонних прокси, выполнения HTML/JavaScript или обхода CAPTCHA. Загружается не более 16 itiles за одну область. Необработанная вложенная детализация означает **неполное** покрытие, даже при успешном ответе. Полная карточка и фотографии остаются на телефоне.

## Сборка и установка
```bash
npm ci
npm run android:sync
cd android
./gradlew --no-daemon testMobileDebugUnitTest testAutoDevDebugUnitTest assembleMobileDebug assembleAutoDevDebug lintMobileDebug lintAutoDevDebug
```
APK: `android/app/build/outputs/apk/autoDev/debug/app-autoDev-debug.apk`. Для проверки установить **только AutoDev** (`org.example.wikimapreader.autodev.next`): оно располагается рядом со стабильным WikiReader Next (`org.example.wikimapreader.next`), не заменяя и не стирая его. Runner-debug mobile APK не подходит для обновления официальной Next; для этого использовать только GitHub Releases с прежним сертификатом.

## Остаточные ограничения
- Android Auto DHU, физический телефон/head unit, GPS, производительность рендеринга, touch, accessibility, фоновые ограничения **НЕ ПРОВЕРЕНЫ**.
- Доступность публичных тайлов и карточек в целевых мобильных сетях не подтверждена на устройстве.
- Два разных package ID не имеют общего приватного хранилища: данные главного Next автоматически не появляются в AutoDev. Проверенная миграция действует внутри того же пакета; безопасный межпакетный перенос — отдельная задача.
- Механизм Java website decoder требует дополнительного реального тестирования и сравнения с JS-парсером.
- Автомобильное UI должно соблюдать Android Auto car host, шаблоны и права установки. Версию AndroidX Car App SDK необходимо сверить с текущими требованиями.
- Проверка подписи мобильного релиза после внедрения product flavors обязательна. Нет разрешения на merge Auto в main.

## Карта на широком экране (улучшение по фото из автомобиля)

- Основной экран API 7+ использует компактный `PaneTemplate` с одним статусом вместо постоянно открытого списка, чтобы не оставлять большую пустую панель; кнопка «Объекты рядом» показывает/скрывает список без выхода с карты.
- Рендер `SurfaceCallback` теперь заполняет *всю* поверхность Android Auto, включая зону под накладными панелями. `onVisibleAreaChanged` определяет центр видимой карты, `onStableAreaChanged` — безопасное положение атрибуции OSM.
- Касание геометрии, pan/zoom, кнопки масштабирования, геопозиция, поиск и избранное остаются на официальных Car App callbacks/templates, без браузерных оверлеев и обхода ограничений водителя.
- Шаблон POI не обеспечивает свободную полноэкранную компоновку как у навигатора: размер системной панели, поддержка жестов и предупреждение «Во время вождения это сделать нельзя» контролируются Android Auto host. Открытие подробностей на телефоне остаётся доступным только на стоянке.
- Сторонний установщик может обеспечить появление тестового APK в автомобиле, но не увеличивает права Car App SDK и не снимает ограничения на отвлечение водителя. Для официального распространения использовать тестовый канал Google Play и подтверждать соответствие требованиям категории POI.

Дополнительные проверки: Robolectric проверяет выбранную видимую область и расчёт тайлов за её пределами, а также компактный/развёрнутый режимы. Реальный автомобиль и DHU требуется проверить отдельно: форма/ширина панели задаются host, поэтому совпадение с Яндекс Картами не гарантируется.

## Компактные карточки во время движения (AA-кандидат)

В Car App API 7+ касание полигона не переводит пользователя в отдельный экран. Вместо этого основной `MapWithContentTemplate` показывает компактную `PaneTemplate` с названием, коротким описанием (максимум 105 символов) и действиями «Маршрут» и «Закрыть». Длинные описания, фотографии и комментарии остаются на телефоне. При пересечении контуров повторное касание переключает выбранный объект. Касание пустой области закрывает карточку.

Описание приходит из публичного сайта Wikimapia через существующий `WikiApi` с keyless site-first; при недоступности сети показывается нейтральная подпись, а не длинная ошибка. Запрос отменяется при смене объекта или закрытии карточки. Нативные шаблоны и разрешённые `SurfaceCallback` не обходят ограничения Android Auto; при движении доступность жестов и расположение панели определяет host, поэтому нужен отдельный тест на автомобиле.

Для API ниже 7 оставлен прежний `PlaceListMapTemplate`. Тестовое приложение AutoDev остаётся отдельным от стабильного WikiReader 0.14.4.
