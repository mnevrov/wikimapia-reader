## Регрессии по фотографиям 01.11.2026

- [ ] Gradle `testAutoDevDebugUnitTest assembleAutoDevDebug lintAutoDevDebug`: лимит кэша >=96 видимых/overscan тайлов, DPI из Surface, отсутствие автоматической повторной загрузки неизменной области.
- [ ] Автомобиль, OSM: после полной загрузки в течение 2–3 минут нет циклического исчезновения тайлов или повторной загрузки без движения.
- [ ] Автомобиль: after pan/zoom/GPS Follow карта появляется без «дыр», переключение полноэкранного/разделённого режима не приводит к неверному масштабу Canvas.
- [ ] Карточки сайта без ключа: заголовок, короткое описание, контуры; отдельно проверить `AutoDev` без VPN и с VPN, а не только основной мобильный пакет.
- [ ] Ошибки сети AutoDev: HTTP 403/429, DNS, timeout и ошибки структуры не сообщаются как «нет объектов»; текст на карте компактный, подробности в «Объекты рядом».
- [ ] Иконки: на автомобильном дисплее нет пикселизации после замены на VectorDrawable; действия распознаваемы и сохраняют доступную область касания host.
- [ ] Проверено, что `main` не затронут и AutoDev остаётся отдельно от стабильного мобильного APK.

Перечисленные аппаратные пункты **НЕ ПРОВЕРЕНЫ** до выполнения реального теста; успешный CI не доказывает их прохождение.

## Приёмка стабильности объектов и GPS Follow (06.11.2026)
- [ ] JVM: один успешный itile + timeout следующих сохраняет объекты, возвращает `complete=false` и безопасное предупреждение.
- [ ] JVM: все недоступные itiles вызывают видимую ошибку, ни один не превращается в ложную пустую карту.
- [ ] JVM: не более 9 тайлов в загрузке, приоритет видимого центра; отмена HTTP не маскируется как частичный успех.
- [ ] JVM: устаревшие или очень неточные координаты не переписывают текущий GPS; `GPS Follow: вкл/пауза` виден на шаблоне.
- [ ] На телефоне AutoDev и Android Auto: без ключа периодически загружать одну область и вручную повторить; по частичной ошибке уже полученные объекты не исчезают.
- [ ] Реальный автомобиль на стоянке и в поездке: Follow включён, смена позиции двигает карту; ручной pan приостанавливает Follow, кнопка GPS возобновляет; zoom не отключает.
- [ ] Surface: PNG/vectors host на автомобиле не «мыльные»; для панелей/атрибуции соблюдены safe areas.
- [ ] Подложка Android Auto — OSM; недоступность Яндекса не представляется как ошибка, требования к отдельному Tiles API зафиксированы в #42.
- [ ] Проверить актуальный именно APK кандидата (а не устаревший AutoDev) и его сертификат/идентификатор; CI artifact != официальный подписанный релиз.
